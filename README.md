# Dummy Robot 复现工程记录

本仓库建立 Dummy Robot 的可审计复现与研究工程记录工作区。目标是先把工程母本中的机械、电气、嵌入式与软件信息转换为可追溯的证据，再以最小实验逐步降低实体实现风险，并最终形成安全的研究平台。

## 双基线

- **V0 数字基线：** 忠实记录并理解 `peng-zhihui/Dummy-Robot` 的结构、传动、控制与接口，用于比较、验证和发现缺失信息。
- **Rev.B 实体双基线：** 在保持其构型、紧凑风格和分布式控制思想的前提下，依据计算与实验进行结构、可维护性和安全优化；不制造完整 V0 实体整机。

## 路线与当前状态

| 里程碑 | 能力门 |
| --- | --- |
| M0 | 读懂原机并建立 V0 数字证据基线 |
| M1 | 形成 STM32 外设、CAN 与调试的最小闭环能力 |
| M2 | 闭环电机可用 |
| M3 | 单关节可用 |
| M4 | 六轴 Rev.B 集成与验收 |
| M5 | 面向系统辨识、控制、视觉和学习的研究接口 |

当前处于 **M0–M1 工作区建立阶段**：已定义工程记录、决策和失败复盘的共同格式；尚未声称任何硬件、固件或实体 CAN 实验完成。

## 工程方法

工作遵循“架构先行、风险优先、最小实验、逐级集成”的闭环：问题 → 证据与推断 → 接线和预测 → 测量 → 验收 → 记录 → 映射回 Dummy。每项结论必须明确为 `evidence`、`inference` 或 `unknown`，不得将推断表述为母本事实。

## 低压安全边界

M0–M1 仅使用 USB、3.3 V 与 5 V 安全低压。不得连接电机、24 V 电源、TB67H450 功率级或谐波减速器。实验必须先记录预期和接线再上电；任何改线前先断开 USB。后续阶段的执行器电源隔离和硬件急停必须独立于研究计算机与主控软件。

## 上游与许可边界

工程母本为 [peng-zhihui/Dummy-Robot](https://github.com/peng-zhihui/Dummy-Robot)。本仓库不重新分发上游源码、CAD、PCB、固件或原始 Git 历史；仅保存独立编写的工程记录与后续获得明确授权的成果。上游资产及其派生成果的许可证与再分发许可仍待审查。
