## 范围

- [ ] 目标、非目标和受影响目录已说明。
- [ ] 未复制或重新分发未经审查的上游资产。

## 交付物

- [ ] 所有计划中的文件、脚本、记录和配置均存在且路径正确。
- [ ] 文档标题、命名与提交引用可追溯。

## 证据

- [ ] 每项结论标注为 evidence、inference 或 unknown。
- [ ] evidence 可定位，inference 有依据，unknown 有后续验证路径。

## 测试

- [ ] 已运行与修改相匹配的测试、结构检查或构建。
- [ ] 已记录命令、结果和未覆盖项。

## 安全

- [ ] 电压、电源隔离、改线断电和急停边界适用于当前工作。
- [ ] 未越过阶段规定的低压安全范围。

## 决策与采购

- [ ] 新决策已记录替代方案、证据、后果和复审条件。
- [ ] 高价值采购有验收前检查，未因未验证假设提前采购。

## 版本管理

- [ ] 工作树状态已审查，暂存内容显式且单一目的。
- [ ] `git diff --check` 通过；未提交密钥、临时产物或无关文件。

## 结论

- [ ] PASS：范围、证据、测试和安全要求满足，可进入下一步。
- [ ] REWORK：存在可修复缺口；列出修正项后重新复核。
- [ ] BLOCKED：存在外部依赖或未决风险；写明阻塞条件与负责人。
