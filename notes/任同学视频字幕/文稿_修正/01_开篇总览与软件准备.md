**[00:00] 开场**

B 站的朋友大家好，我是不爱学习的任同学。今天为大家分享的是一个没有工科经验的人复刻稚晖君 Dummy 机械臂的全过程。期间会保姆级地介绍硬件、软件，以及遇到一些常见故障的解决方法，争取让每一个想要制作 Dummy 机械臂的人都可以复刻成功。

在这里首先要感谢 B 站那些对 Dummy 机械臂做二次开发的 up 主，让以前想都不敢想的项目现在可以实现。下面请允许我展示一下我的机械臂，然后开启今天的课程。

**[00:36] 功能展示一：DummyStudio 上位机**

首先展示的第一个功能，是稚晖君开发的上位机 DummyStudio ⚠️（原字幕作"刷碗机"，疑为"上位机"误识别）。插上 USB 线连接机器人之后，输入 `!start` 就可以使所有电机进入使能状态。

这个时候我们关闭使能，进入手动调节环节，就可以使机械臂自由运动，就像这样——我们可以任意调节，所见即所得。

当然也可以从这里输入坐标点，然后点击 Send，它就会按照你设置的坐标点来移动。坐标可以设置 `MOVJ` 或者 `MOVL`，即世界坐标系和关节坐标系⚠️（严格说 MOVJ 为关节插补、MOVL 为直线插补，此处表述与常规定义略有出入），这个后面会讲到。

**[01:22] 功能展示二：Ubuntu 下用命令行控制**

第二个要展示的是在 Ubuntu 环境下使用 Linux 命令执行机械臂控制的方式，也是我平时比较多用的一种方式。比如……这个时候把速度调到最快，其实它还是比较丝滑的。

**[01:49] 软件一：Altium Designer**

首先要使用的第一个软件是 Altium Designer，它是一个电路图绘制软件。我们在上面主要是用来看看它是怎么布线的，还有它的三维外观，包括我们到时候贴片该怎么贴，以及一些电路原理上的东西。因为只有这样，我们遇到故障的时候才能更好地去维修。当然大家也可能没有电路基础，也可能是大佬，这一点就不再复述。

**[02:36] 软件二：Fusion 360**

第二个我们会用到的软件叫做 Fusion 360，可以看左上角。它是一个 3D 建模软件，我们既可以建模也可以查看，并且可以生成各种各样格式的文件，也可以生成 3D 打印文件，比较好用。我们想要什么样的配色，都可以在这里面编辑。

当然你要是玩得很溜，也可以直接重新生成一个模型，建一个属于你自己的造型⚠️（原字幕"纲领"不可解，疑为某个具体机型名），就像论坛里的大佬一样——他做了一个 VR 版本。我们先把它换一个颜色，可能就是这样。

**[03:32] 软件三：代码编译环境（VS Code / CLion）**

第三个软件是代码的编译软件。Windows 下用的是 VS Code，Ubuntu 虚拟机下用的是 CLion。我们更多的编译是用在 Ubuntu 上，因为 Ubuntu 的环境已经配好了；而你使用 VS Code 还要再配这个环境，包括配置 PIO（PlatformIO）很多东西。可能大家网络不好，PIO 一直配置不好，一配置就配一晚上。所以后面还是建议大家在 Linux / Ubuntu 上进行编译。

VS Code 可以进去看一下代码。稚晖君的这个代码其实底层做得非常好，包括每一级的目录。虽然我不懂编程、现在正在学，但我还是把能看懂的都加了注释，等后续我再给大家分享。里面有一些 Dummy 的 .c 文件、.h 文件，就是我的控制、IMU 的控制，还有一些字库、USB 等等。我现在是能理解他这个代码是怎么调用的逻辑，但由于不懂 C 语言、C++ 和 Python，所以很难说去再写一行主函数把它调用出来。我尽我最大的能力把我知道的分享给大家。

**[05:00] 软件四：Ubuntu 虚拟机**

第四个就是刚刚视频里看到的 Ubuntu，即 VMware 虚拟机下的一个 Linux 系统。我们用的是 Ubuntu 22.04⚠️（原字幕"22.50"，按常见 LTS 版本推断为 22.04）。这个界面非常好，因为它简单、运行也比较快。当然这些大佬们都已经给配好了，我们直接从网盘上下载下来就可以直接使用。

我们可以输入命令打开 CLion（不知道单词有没有读对）这个编译器，它其实和 VS Code 是一致的，只是它更倾向于 C++ 编译环节。后续我会讲我们该如何编译、该怎么烧录，遇到像开路这些问题该怎么解决、如何 debug，这些我都会一点点讲。因为 B 站上的大佬确实比较厉害，他没有时间讲那么详细；我这个就是主要针对小白的保姆级课程，让大家能复刻出来、做出来一个东西。至于大家想不想更深入地学习，就看个人兴趣爱好。

**[06:30] Ubuntu 下的其他工具**

在 Ubuntu 环境下还有很多其他工具，例如 STM32CubeProgrammer，它可以直接烧写二进制文件，烧到 ROM 里⚠️（原字幕"论坛"，此处疑为"ROM"或"芯片"），直接写好二进制文件会更快一点。不过对于没有基础的来说，跟着我的视频的话，大家可以不用这么烧录，可以直接在 CLion 里面一步步编译，并且查到我们自己到底有哪些问题、问题出在哪里，一步一步来。

另外我有的时候也会用 STM32CubeIDE ⚠️（原字幕"c link"，疑为 CubeIDE 或 ST-Link 相关工具）来进行编译。

**[07:14] 平台：嘉立创**

最后说的一个软件，也不算软件，算是一个商城，就是嘉立创。在这里面我们可以进行 PCB 板的下单、SMT 的下单。

什么是 SMT？一开始我连 SMT 是什么都不知道，后来才知道它就是帮我们把板子上的芯片都贴好，当然很贵。如果大家动手能力差，可以直接用 SMT 下单，但这样成本就会变高；想要尝试自己手焊的话，就可以在上面打板。我打了很多板，最近一直在研究一些小玩意儿。我们找一个文件上传之后，就可以直接下单了。

其实不光嘉立创，还有其他平台可能会有免费打样，然后我们就可以算是白嫖一波。但主要是不白嫖其实也不贵，可能在 20 块钱左右。

当然我们做 CNC 也可以在嘉立创平台里面进行。我们点开 CNC，然后上传需要的 step 图纸，打开它就会给你进行报价。相对较贵，你也可以走淘宝，但淘宝的精度可能没有我们需要的——我们需要在这里修改一些精度，因为这个模型其实是论坛大佬做的，要求精度很高，都在 ±0.05 左右，所以它的价格会更高一点。图纸和文件我最后会打包一起发给大家。

**[09:20] 如何下载开源文件（GitHub / Gitee）**

然后就是我们该怎么去下载这些开源文件。其实作为一个小白来说，我最开始想下载这些东西都下载不了、搞不懂。我们可以在百度上直接搜 GitHub，点开之后注册一个账号（我注册过了，就不演示怎么注册了）。

然后在里面直接搜索 "Dummy"，有点卡。稚晖君的是在 GitHub 上，而木子的是在 Gitee，但木子的在 GitHub 上也有。在 Gitee 里面是国内环境，相当于说会快一点。我们输入关键词搜索一下，就会找到稚晖君的 Dummy-Robot，我们点开。

这还有个绿色的下拉按钮，这里有个 Download ZIP 就可以下载了。我下载好了就不再下了，大家可以从这下。另外木子的从这里面也可以找到。

我们返回一下就可以看到，在 Gitee……我怎么看不懂呢，就不从那找了吧，还是从他自己的 Gitee 里面找。直接搜索、注册一下，点开之后就会进入文件里面。我们同样输入关键词，第一个是稚晖君的⚠️（原字幕"孔指挥"，疑为"稚晖君"），第二个这个 Switch Pi Dummy ⚠️（名称存疑）就是木子的，它有三个分支。

木子的这个是主分支，这个是 auk。在这里面就可以看到所有的，包括硬件、软件、驱动、ESP32，还有木子写的 Python 示例⚠️（原字幕"Python simple"），包括一些图片什么的。

包括也是从那边下载的。早的时候我连怎么下载都不会，比较笨吧。木子设计的其实也非常好，好在他的工坊里面也可以直接购买。

**[12:01] 开源仓库目录结构**

下载完了之后，我们以稚晖君的为例，就可以看到它有 Hardware、Software 等目录。因为稚晖君和木子的区别，最大的区别就在于 35 电机和 42 电机的区别，所以板子也分为 42 和 35 ⚠️（原字幕此处数字识别混乱；按仓库实际目录 `motor42` 对应 J1/J2/J3、`motor35` 对应 J4/J5/J6）。

我们点开这些文件就需要用 Altium Designer 打开。包括我们回来贴板子可能会用到一个小插件，后面会告诉大家怎么用，这样贴片的时候就会比较省事，会直接看见在哪个位置。

木子的板子有个特别大的好处，就是他做了丝印⚠️（原字幕"做了C"），可以直接在板子上面就看见哪些是几级⚠️；而稚晖君的 REF 板它就需要用这个插件来根据位置来判断再去贴，当然也无伤大雅。

**[13:13] 固件与软件目录**

包括这个软件，它有两个固件：一个是 Core，就是带驱动板的⚠️（原字幕此处"驱动/驱动版"反复，表述混乱；按仓库实际，`dummy-ref-core-fw` 为 REF 主控板固件，`dummy-42motor-fw`/`dummy-35motor-fw` 为电机驱动板固件）。我们使用 VS Code 或者使用 Ubuntu 下的 CLion 都可以打开它进行编译。

然后在 Software 里面就是一些工具，即 CLI-Tool，也就是我们在 Linux 下使用的一个工具，用代码命令机械臂该怎么运动、控制它的一些参数，包括 PID、RGB，还有一些电机的电流限制，这些东西都可以在 CLI-Tool 里面实现使用。

第二个 DummyStudio，就是我们所见即所得的一个上位机图形化界面，但它相对来说功能比较少。

然后这个是稚晖君的模型。有些人看到论坛上面找不到模型在哪里，其实就是这个，这是稚晖君的主模型。而木子的模型就在 3D Model 里边，这里边有直接给你设置好的，可以直接打印。当然我当时在群里面比较早，也有他的 3D 建模和 CNC 的文件。
