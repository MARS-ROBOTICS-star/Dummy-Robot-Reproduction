## 一、核心方法论：先通电，后上芯片

这是 UP 主烧了很多块板子之后总结的唯一一条铁律（06 集 [03:23]、[27:08]）：

1. **先只焊电源部分**，所有芯片一律不装
2. 上电，**确认 3.3V 正常**
3. 再焊 MCU（STM32）
4. 再焊 MT6816（磁编码器）+ SN65HVD232DR（CAN 收发器）
5. 再焊两颗 TB67H450FNG（电机驱动）
6. **最后**焊 K1/K2 微动开关
7. 上电前逐引脚测通断

**第一步不焊的清单**（06 集 [27:25]）：MT6816、CP2102、ESP32、CAN 芯片、STM32、IMU、屏幕 —— 凡是需要 3.3V 供电的，全部先不焊。

> 理由：电源部分没调通就把芯片全贴上，一旦电压异常（比如 3.3V 被短到 5V），MCU、驱动芯片、编码器芯片会一起报废。

**微动开关放最后**的原因（06 集 [22:17]）：前面工序会用掉很多松香，松香渗进微动开关会把它粘住失效，表现为**电机不自动校准**。排查第一步就是按下开关看万用表蜂鸣档响不响。

## 二、热风枪参数与操作（07 集全集）

| 项 | 值 |
|---|---|
| 温度 | 300℃ 左右，**不要高于 300**（06 集 [03:02]） |
| 风量 | 调到最低 |
| Type-C 可临时提高到 | 380℃（07 集 [05:31]） |
| 驱动芯片上限 | 超过约 350℃ 就烧（03 集 [23:01]） |

操作要点：

- 板子用**台钳**卡住（07 集 [00:36]）
- ⚠️ **不要一上来就吹小元器件**，先把整板吹热，否则元器件直接被吹飞
- 一手风枪一手镊子，风枪垂直
- **判断板子温度到了**：看焊点全部变成锡球（07 集 [01:44]）
- 由近到远吹
- 5V 芯片吹完后用镊子**拿起来再重新放一次**，避免底下连锡
- ESP32 用风枪直贴**必然连锡** → 趁热用镊子把锡珠挑开（07 集 [02:12]）
- ⚠️ **Type-C 最难焊、最容易虚焊**：放到最后焊，先给足助焊剂，需要的加热时间更长。这片区域温度上不来，先找个大片器件把周边板子吹热
- ❌ **不要**"先把焊盘吹成锡珠、再放件、再吹"——他实测过，这样特别容易虚焊（07 集 [02:55]）
- CAN 芯片不太耐温，**建议改用烙铁**焊（07 集 [03:42]）
- ESP32 第一次吃不上锡就没救了，要用烙铁拖锡补（07 集 [05:09]）
- QFN（引脚在底下）的件：风枪很难焊，锡太少时要用烙铁一点点补锡、边吹边抬（06 集 [29:31]）

**强烈建议打一张钢网**（04 集 [01:32]），20~30 块。不打钢网直接挤锡膏，对手法要求太高。
PCB 打样一次给 6 张，**拿两张废板焊 ESP 芯片练手**（06 集 [30:08]）。

## 三、⚠️ 六个会烧板子的坑

### 1. R27 / R28 两个 0Ω 电阻不能都焊（02 集 [10:40]、03 集 [09:24]）

HD3 插口旁有两颗 0Ω 电阻，一颗接 3.3V、一颗接 5V。**0Ω 电阻就是一根导线**。两颗都焊上 = 把 3.3V 和 5V 短接，结果：

- 一直测不到 3.3V
- 全线电压变成 5V
- **换多少颗电源管理芯片都没用**

UP 主本人就踩了这个坑，换了好几颗 3.3V 芯片才发现。RGB 那路需要 5V，3V3 那颗不用焊。

> ⚠️ **编号不要信字幕**：他前后说成"27 和 29""R27 和 28""R7 和 R29"三种。**务必对着原理图/丝印自己确认哪一颗不焊**。

### 2. CAN 芯片极易烧，而且是连锁反应（02 集 [18:32]）

24V 和 CAN 走在**同一个 6P 插口**上，物理位置紧邻。插口稍微歪一点，24V 碰到 CAN_H / CAN_L：

- 立刻烧掉该板 CAN 芯片
- **沿链路连锁烧**：J6 出事会一路烧到 J5→J4→J3→J2→J1，连 2.4G 那边都烧
- 一两秒内没断电基本全军覆没

对策：6P 线**插到底、插牢**，别半插。

### 3. 插错 6P 口直接烧板（02 集 [15:51]、03 集 [25:44]、06 集 [23:55]）

- SWD 烧录口 和 CAN 通讯口长得像，**插错板子就烧**
- 把 **24V 插到 MCU 烧录口** → 烧主控 + CAN 芯片 + 一串
- 42 电机板的 P3 口是 STM32 通讯口，**输入/输出不能反**

他在 02 集里反复强调并自己纠正了一次位置："引脚可别插错了，插错板子就烧了"。

### 4. TB67H450FNG 驱动芯片不耐热（06 集 [04:17]）

温度一高就失效，症状是**电机抖动、无法自动校准**。稚晖君原板给它加了散热片。
焊接时"快准狠"，别反复加热。

### 5. MT6816 编码器的两个硬约束（06 集 [24:34]）

- 必须**焊正**
- 与电机之间必须留约 **5mm 间隔**（靠 3D 打印垫片），否则编码器根本不工作

### 6. 磁铁必须是径向充磁（03 集 [14:51]）

磁铁装在电机轴正中心，**必须径向充磁**。如果是轴向（"竖着"）的，磁感线切不到，编码器检测不到方向。

## 四、万用表：只需三个档（06 集 [05:02]）

直流电压档、电阻档、蜂鸣（通断）档。**买细表笔**，粗表笔测不了 PCB。
对地找法：所有电容的一端就是负极 / 地。
习惯单手操作。

### 电压排查链（没有 3.3V 时逐级往上查）

| 查什么 | 测点 | 期望值 |
|---|---|---|
| 3.3V | REF 板：RST 旁两个测试过孔<br>驱动板：C22 两端 / R31 一端 | 3.3V |
| ↑ 没有就查 5V | SY8089A 旁，R34 一端（开关电源下拉电阻） | 约 5.2V |
| ↑ 没有就查 24V | 大电容两端 / 浪涌保护二极管两端 | 24V |
| 24V 有、5V 没有 | 检查那两颗二极管**是否焊反** | — |

42 板有现成测试点；**35 板的 LP2992（3.3V 电源管理）在背面**（06 集 [32:31]）。
UP 主自己那块板嘉立创把过孔盖油了，正常应该是两个裸过孔。

### CAN 通讯通不通（03 集 [05:17]）

用通断档量 6P 插针第 3、4 脚（CAN_H / CAN_L）与对端 REF 板对应脚：
- 直通 → 线序正常
- 交叉通 → 线做成交叉了

## 五、焊完必做的自检（06 集 [30:53]、03 集 [12:11]）

> "你看着好像焊得很好，实际上有个肉眼不可见的小连锡，这个芯片就废了。"

1. **所有多引脚芯片，相邻引脚两两量通断**。有滴声 = 连锡。STM32 的 48/64 个引脚全量一遍
2. QFN 件（IMU、CP2102、MT6816、CAN 芯片）引脚在底下，**最容易虚焊**。合格标准：**每个引脚都长出一点小尾巴**
3. 屏幕不亮，绝大多数是 **IMU 或 OLED 虚焊**（03 集 [11:44]、06 集 [28:45]）
4. **上电前必须查完连锡**。一上电有连锡，芯片当场坏
5. 屏幕排线极脆弱，来回晃几下就断，装的时候别反复折

> 他的原话：电路/电气工程师最重要的素质可能就是仔细。花在返工上的钱和时间，不如多检查一遍。

## 六、ST-Link 烧录接线（06 集 [23:14]）

只用三根线：**GND、SWDIO、SWCLK**，接排针的 **4 / 5 / 6**（下排）。
排针一端有缺口、一端没有，靠缺口定位。

⚠️ 他在视频里先说"上面三根"，随即改口为"下边 456"。**按板子丝印和原理图核对，不要照搬线缆颜色**。
⚠️ 千万别把 24V 插到 MCU 烧录口。

### 校准指示灯状态（06 集 [24:57]、[25:19]）

| 状态 | 指示灯 |
|---|---|
| 未校准 | 一个常亮，另一个闪烁 |
| 校准中 | 按 K1 键约 5 秒，电机左转 2.5 圈、右转 2.5 圈 |
| 校准成功 | 慢闪三下 → 两个灯都常亮 |
| 使能状态 | 电机拧不动（有力矩） |

测板子好坏最快的办法：通电后给电机做一次校准。校准数据记录在**驱动板的 STM32**里（不是 REF 板），本质是编码器数据（11 集 [21:24]）。

## 七、焊接阶段最容易误判的三个症状

| 症状 | 先查什么 |
|---|---|
| 屏幕不亮 | IMU / OLED 虚焊，及其旁路电阻电容 |
| STM32 烧录不了 | **第一时间查有没有 3.3V**。注意 LED 灯在 5V 下也会亮，灯亮不代表 3.3V 正常（02 集 [20:12]） |
| 能烧录但连不上串口 / 找不到 robot 串口 | Type-C 座子虚焊。Type-C 到 STM32 之间没有任何元器件，DP/DN 直连（02 集 [12:40]） |

ESP32 烧不进去只有三种可能（03 集 [06:39]）：买到假片、虚焊、Q1 使能芯片坏。CP2102 还需要装驱动。
