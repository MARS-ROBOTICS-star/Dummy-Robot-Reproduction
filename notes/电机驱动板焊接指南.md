## 一、先焊哪块：**先焊 42 板**

| 对比 | Motor-42 | Motor-35 |
|---|---|---|
| 电源链在哪 | **全在正面**（D1、ME3116、LP2992、R20 都在正面） | **跨两面**：D1、LP2992(U7)、R20、C21、C22 在**背面** |
| 测试点 | 正面有 **T1(5V)、T2(3.3V)** | 只有背面的 T2(3.3V)，没有 5V 测试点 |
| 背面有什么 | 只有 2 颗 SO-8 + 8 颗 1206，**烙铁很好焊** | 2 颗 SO-8 + SOT23-5 + SMA 二极管 + 1206 + 4 颗 **0402** |
| 板子大小 | 41.2 × 41.2 mm，元件间距宽 | 更小，元件更密 |
| 任同学视频 | 主要演示的是 42 板 | 他说 35 板的 LP2992 在背面，要拆下来才能看到（06 集 [32:35]） |

结论：42 板可以严格按「**先焊电源 → 上电测 5V/3.3V → 再焊芯片**」的顺序做，而且正面的两次焊接都能用加热台。35 板的电源测试要先把背面焊上，背面焊了之后板子就不能再放回加热台了，难度更高。

**建议的总顺序**：
1. 先**完整焊好 1 块 42 板**，测完电源，焊完芯片，能用 ST-Link 识别到芯片、能烧录固件
2. 确认这块没问题后，再一起焊另外 2 块 42 板。第一块能帮你发现系统性错误，比如某个料买错了值，这时只损失一块
3. 最后焊 3 块 35 板

⚠️ **关键芯片基本没有备件**（按你的采购表）：STM32F103CBT6 买了 6 颗、MT6816 6 颗、TB67H450FNG 12 颗、LP2992 6 颗、拨码开关 S1 6 个，**余量都是 0**。烧坏一颗就得补货。所以「先通电再上芯片」这一条一定要严格遵守。

## 二、开工前的准备

### 1. 必备工具（对照你的工具采购表）
| 工具 | 状态 | 说明 |
|---|---|---|
| 加热台、热风枪、电烙铁、镊子、锡膏、万用表 | ✅ 已有 | — |
| KUAIQU 30V 稳压电源 | ✅ 已有 | 可以直接输出 24V 并限流，**比用 24V 适配器安全得多** |
| T6 夹具 | ✅ 已有 | 焊背面时用来夹住板子，避免正面的元件压在桌面上 |
| **吸锡带**（1.5–2 mm） | ❓ 表里没有 | **建议买**。LQFP-48 引脚间距只有 0.5mm，没有钢网的话几乎一定会连锡，要靠吸锡带清理 |
| **ST-Link V2** | ❓ 表里没有 | 烧录固件必须要有。江协课程如果已经配了一个就不用再买 |
| 免洗助焊膏、洗板水/酒精、细表笔 | 酌情 | 任同学强调**表笔要买细的**，粗表笔测不了 0402 和芯片引脚 |
| **钢网** | ❌ 没打 | 见下面 |

### 2. 强烈建议给 42 和 35 打钢网
任同学原话（04 集 [01:32]）：**强烈建议打钢网**，不打钢网直接挤锡膏，对手法要求太高。灯环焊盘大，用针筒点就够了；电机板有 LQFP-48（0.5mm 间距）、40 多颗 0402、TB67 底部的散热焊盘，用钢网刮锡膏又快又均匀。

- 下单嘉立创钢网时，选**只开正面（顶层）**，用对应板子的 V1.01 Gerber（`source/dummy/hardware/motor42/motor42-gerber.zip`、`motor35/motor35-gerber.zip`）
- 等钢网的时候可以先用针筒焊第一块，下文两种方法都写了

### 3. 交互式 BOM 一定要打开
用浏览器打开 `source/1.Dummy V2任同学整理/1.Hardware/motor42/Motor-42.html`（35 板用 `motor35/Motor-35.html`）。点表格里的某一行，板图上会**高亮这个元件的所有位置**。放 0402 时一行一行地放，放完一行勾一行，不容易漏、也不容易错。

### 4. ⚠️ 分料时不要按采购表的「对应位号」来
你的 `实际采购iBOM` 里「对应位号」那一列，很多是**主控板（REF）或别的表的编号**，和电机板丝印**对不上**。比如：ME3116 写的是 U8（电机板上是 **U6**），SS54 写的是 D2（电机板上是 **D1**），SMBJ28CA 写的是 D3（电机板上是 **D2**），1N5819 写的是 D4/D5（电机板上是 **D3/D4**），220µF 写的是 C6（电机板上是 **C11/C14**）。

**分料一律以本文第五节的表和交互式 BOM 为准，按「值 + 封装」认料。**

### 5. 两种晶振别拿混
采购里有两种 3225 晶振：**12 MHz**（扬兴 YXC，电机板 Y1 用）和 **8 MHz**（雅晶鑫，REF 主控板用）。电机板必须用 **12 MHz**，焊之前看清晶振上的丝印 `12.000`。拿错了单片机能跑，但时钟全错，CAN 通讯会失败。

### 6. 光板检查（每块板都要做）
用万用表蜂鸣档测下面几组，**都不应该响**。如果光板就短路，那是板厂的问题，换一块板：

| 测哪两点 | 42 板 | 35 板 |
|---|---|---|
| 24V 输入 和 地 | P1 的 `+24V` 孔 和 GND 孔 | 同左 |
| 5V 和 地 | T1 和 任意 GND | C19 两个焊盘 |
| 3.3V 和 地 | T2 和 任意 GND | T2（背面）和 GND |

P1 的引脚定义见第七节。

## 三、原理弄懂一点点：电源是怎么来的

```
P1/P2 的 +24V (VCC_IN)
   │
  D1 SS54（防反接：电源接反时它截止）
   │
  VCC（24V 主电源，也给两颗 TB67 电机驱动供电）
   ├─ D2 SMBJ28CA（双向 TVS，吸收浪涌）
   ├─ C11/C14 220µF + C29~C34 10µF/50V（储能、滤波）
   │
  D4 1N5819 ──→ U6 ME3116（降压 DC-DC）── L1 6.8µH ──→ VCC_5V（约 5.2V）
                  ├─ D3 1N5819（续流二极管）              │
                  └─ R13 10K / R14 1.8K（反馈分压，决定输出电压）
                                                          │
                                              U7 LP2992 ──→ VCC_3V3（STM32、MT6816、CAN 芯片）
```

**为什么一定要先测电源，再焊芯片**（这是我从原理图里看出来的，正好解释了任同学「电压超了把芯片全烧了」那句话）：
- **R13 虚焊或漏焊**：反馈脚被 R14 拉到地，ME3116 会以为输出电压太低，一直往上推，**5V 这一路会变成接近 24V**。这时 LP2992（输入上限只有十几 V）、STM32、MT6816、CAN 芯片会一起烧掉
- **R13 和 R14 对调**（两颗都是 0402，就挨在一起）：输出会变成大约 0.9V，芯片不工作，但不会烧
- **D3/D4 焊反**：任同学说过「24V 有、5V 没有，先查这两颗二极管是不是焊反了」（06 集 [20:20]）
- **R20 没焊**：功率地 PGND 和信号地 GND 断开，整块板没有共地

所以第一次上电前，**芯片一颗都不要焊**。先确认 T1 ≈ 5.2V、T2 = 3.3V，这时候就算出了问题，坏的也只是几毛钱的电源芯片。

## 四、两种流程怎么选

| | **流程 A：一次回流**（Ryan 视频里的做法） | **流程 B：分两次回流**（下面第五节写的） |
|---|---|---|
| 正面 | 正面元件全部点锡膏、放好，**加热台一次焊完** | 先焊电源，测完电压，再焊芯片 |
| 背面 | 锡膏 + 热风枪 | 烙铁 |
| 优点 | 快；**TB67 只受热一次**（任同学说它不耐热） | 测电压时芯片还没装，出问题不会烧芯片 |
| 风险 | 电源有问题（比如 R13 虚焊）时，第一次上电芯片会一起烧掉 | TB67 要多受热一次；步骤多 |

**两种都可以，我推荐流程 A，但要加三条保护措施**。这样能保住流程 B「不让芯片挨高压」的好处，又不用多回流一次。

### 流程 A 的做法（42 和 35 板都适用）

1. **正面一次回流**：正面所有贴片元件都点锡膏、放件，上加热台，温度和第五节阶段 ① 一样
   - **K1、K2、S1 不放**，留到最后用烙铁焊（任同学：松香会把开关粘住）
   - 插座 P1/P2/P3 是直插件，本来也是最后焊
2. **回流后彻底检查**：芯片 1 脚、二极管和电解电容方向、R13/R14 没对调；STM32 和 TB67 相邻引脚逐对测通断；24V–GND、5V–GND、3.3V–GND 三组都不能短路
3. **背面**：
   - MT6816（U8）：锡膏 + 热风枪可以，或者用烙铁
   - **CAN 芯片 U5 用烙铁**：任同学说它不耐热；而且在 42 板上，U5 正对着正面的 S1 拨码开关
   - **C29~C34（1206）用烙铁**：在 42 板上，其中 5 颗正好压在两颗 TB67 的正下方。用热风枪吹它们，等于从背面再把 TB67 烤一遍，而且这时 TB67 是倒挂着的，焊锡熔化后可能会移位
   - 热风枪 **300℃、最低风量**，板子夹在 T6 夹具上，正面元件悬空，不要压在桌面上；对准目标元件局部吹，不要大范围来回扫
4. **⚡ 第一次上电先用 9V，不要直接上 24V**（这是保护措施的关键）：
   - 稳压电源调到 **9.0V，限流 0.10A**，从 D1 正极和 R20 接临时引线（或者插座焊好后从 P1 进电）
   - 原理：ME3116 的输入范围是 4.75–40V，9V 也能正常输出 5.2V。**如果 R13 有问题、5V 失控，这一路最多也只到 8V 多**。LP2992 能承受这个电压，3.3V 照样稳住，STM32、MT6816、CAN 芯片都不会坏；5V 上的 10V 耐压电容也不会过压
   - 测 **T1 ≈ 5.2V、T2 = 3.3V**（35 板测 C19 和 T2）。**如果 T1 接近 8–9V，说明 R13 开路**，断电修好再测
   - 9V 下一切正常，再把电压调到 **24V** 复测一次
5. 焊插座 → 最后焊 S1、K1、K2 → 按第七节做整板测试和烧录

> 如果你想更稳一点，第一块板用流程 B，熟悉之后其余板子改用流程 A，也完全可以。

## 五、Motor-42 板：分阶段焊接（流程 B，照图 [Motor42分阶段焊接图.png](Motor42分阶段焊接图.png)）

### 阶段 ① 电源部分（加热台第 1 次，只焊正面）

| 位号 | 物料 | 注意 |
|---|---|---|
| D1 | SS54（SMA 封装） | **有极性**：色环（负极）朝 VCC 一侧，图上标了 K。正极那头朝 P1 |
| D2 | SMBJ28CA（SMB 封装，较大） | 双向 TVS，**不分方向** |
| D3、D4 | 1N5819WS（SOD-323，很小） | **有极性**：色环 = 负极，对准图上的 K。任同学踩过坑 |
| U6 | ME3116（SOT23-6） | **对准 1 脚**（黄点）。SOT23-6 转 180° 也放得进去，一定要看清 |
| L1 | 6.8µH（2016 封装） | 无极性 |
| R13 | 10K（0402） | ⚠️ 反馈上臂，**虚焊会让 5V 变成 24V** |
| R14 | 1.8K（0402） | 反馈下臂，**和 R13 不能对调** |
| R15 | 1M（0402） | ME3116 使能脚上拉 |
| C15、C17 | 0.1µF（0402） | 自举电容 |
| C16 | 100pF（0402） | 反馈补偿 |
| C18 / C19 | 0.1µF / 10µF（0402） | 5V 输出电容 |
| C20 | 10µF/50V（1206） | ME3116 输入电容 |
| U7 | LP2992-3.3（SOT23-5） | 一边 3 个脚、一边 2 个脚，方向放反了是放不平的 |
| C21 / C22 | 0.1µF / 10µF（0402） | 3.3V 输出电容（任同学测 3.3V 就测 C22 两端） |
| C35 | 0.1µF（0402） | LP2992 的旁路电容 |
| R20 | 0Ω（1206） | **必须焊**：把 PGND 和 GND 连起来 |

**操作**：
1. 只在上面这些元件的焊盘上点锡膏，然后放件（锡膏的量参考灯环：0402 每个焊盘只要针尖大小一点）
2. 加热台**两段升温**：先 150℃ 预热 60–90 秒，再升到 **200–205℃**（你上次实测锡膏在显示不到 200℃ 就化了）。焊点全部变亮后 **10 秒内**取下，自然冷却
3. 放大检查：0402 有没有「立碑」（一头翘起来），二极管方向对不对，U6/U7 引脚有没有连锡
4. **重新测一遍第二节第 6 步的三组短路**，都不能响

### ⚡ 第一次上电：只测电源
这时还没有焊 P1 插座，用**临时引线**供电：
1. 剪两根短导线：**红线焊到 D1 的正极焊盘**（没有色环、靠近 P1 的那一头），**黑线焊到 R20 的任意一端**（R20 焊好后，两端都是地）
2. 稳压电源：先**不接板子**，调到 **24.0V**，用短接法把限流调到 **0.10A**（方法见灯环指南第六节，同一台电源）
3. 接上：红夹子 → 红线，黑夹子 → 黑线。按 OUTPUT
4. 观察：**C.V 灯亮**，电流很小（显示 0.00–0.02A 都正常）。**如果 C.C 灯亮了、电压掉下去，马上关输出**
5. 用万用表直流电压档测（黑表笔接 R20）：

| 测点 | 应该是多少 | 不对的话先查什么 |
|---|---|---|
| D2 或 C20 两端 | 约 23.5V（比 24V 少一个二极管压降） | 0V：D1 焊反或虚焊 |
| **T1** | **约 5.2V**（任同学实测 5.22V） | 0V：D4/D3 焊反，U6 方向，L1 虚焊。约 0.9V：R13/R14 对调。**接近 24V：R13 开路，马上断电** |
| **T2** | **3.3V** | 0V：U7 方向或虚焊，C22 短路 |

6. 两个电压都对了，**断电，拆掉两根临时引线**，把焊盘清理平整

### 阶段 ② 正面其余元件（加热台第 2 次）

| 类别 | 位号 | 物料 | 注意 |
|---|---|---|---|
| 主控 | U3 | STM32F103CBT6（LQFP-48） | **1 脚对准**（芯片上的小圆点对准丝印缺角或黄点） |
| 晶振 | Y1 | **12 MHz** 3225 | 4 个焊盘，**对准 1 脚标记**，转 90° 会把晶振脚短到地 |
| | C12、C13 | 20pF（0402） | 晶振负载电容 |
| 电机驱动 | U1、U2 | TB67H450FNG（SO-8，底部有散热焊盘） | **1 脚对准**；底部中间的大焊盘也要上锡膏，见下文 |
| | R1、R2、R6、R7 | 1K（0402） | |
| | C1、C2、C4、C5 | 0.1µF（0402） | |
| | C27、C28 | 0.1µF（0402） | ⚠️ **接在 24V 上**，见第九节第 1 条 |
| 温度检测 | R4 / R5 / C3 | NTC 热敏电阻 NCP15XH103 / 3.3K / 10µF | R4 长得和普通电阻一样，**别和 10K 电阻混了** |
| 电容 | C11、C14 | 220µF/35V 电解电容 | **有极性**：正极对准图上的 + 和丝印 +。电解电容外壳顶部黑色那一侧是负极 |
| 单片机外围 | R9、R10 / R19 | 10K / 1M | |
| | C6~C9、C23 / C10 | 0.1µF / 10µF | |
| | R21、R22 | 0Ω（0402） | 模拟地和数字地相连，**两颗都要焊**（和 REF 板那两颗「不能都焊」的 0Ω 不是一回事） |
| 指示灯 | LED1、LED2 / R11、R18 | 绿色 0603 LED / 1K | LED 有极性，用万用表二极管档点亮来确认负极，再对丝印 |
| 编码器外围 | C24 / C25 | 10µF / 0.1µF | MT6816 的去耦电容（芯片本身在背面） |
| 电压检测 | R16 / R17 / C26 | 10K / 1K / 0.1µF | 24V 分压送给单片机测电源电压 |
| CAN 外围 | C36 / R12 | 0.1µF / 120Ω | R12 是终端电阻，由 S1 第 4 位控制接不接 |

**TB67H450FNG 的散热焊盘**：
- 中间大焊盘上的锡膏**不要涂满**，涂成「井」字或 4 个小点，覆盖约一半面积就够
- 锡膏太多，芯片会被顶起来「浮」在锡上，四周引脚就接触不到
- 回流后看芯片是不是**平贴**在板上，8 个脚都要有焊锡

**LQFP-48 没有钢网怎么上锡膏**：
- 沿每一排焊盘挤一条**很细的线**（比焊盘宽度还细），放上芯片对齐后回流
- 回流后**多半会有几处连锡，这是正常的**。涂一点助焊剂，用烙铁沿引脚往外拖，或者用吸锡带吸掉多余的锡
- 第一次焊之前，建议先拿你买的 **SMT 练习板**练一下 LQFP

**回流**：温度和第 1 次一样。电源部分会再熔化一次，这是正常的。**TB67 不耐热**（任同学：温度一高就失效，表现是电机抖动、无法校准），所以不要在高温段多停留。

**回流后检查（最重要的一步）**：
1. 放大镜逐个检查每颗芯片的引脚
2. 万用表蜂鸣档：**STM32 的 48 个脚，相邻两脚逐对测**，TB67、晶振也测一遍。任同学原话：「看着好像焊得很好，其实有个肉眼看不见的小连锡，这颗芯片就废了」
   - 如果测到响，先看原理图这两个脚是不是本来就连在一起的（比如两个都是 GND），不是的话就是连锡
   - 测 3.3V 和 GND 时，表可能「嘀」一下就停，那是电容在充电，不算短路
3. 再测一次：24V–GND、T1–GND、T2–GND 都不能短路

### 阶段 ③ 背面（烙铁，板子不能再上加热台）

| 位号 | 物料 | 注意 |
|---|---|---|
| U8 | **MT6816**（SO-8） | 磁编码器。**必须焊正、焊平**（任同学：编码器要焊正）。1 脚对准黄点。焊之前用放大镜核对丝印 `MT6816CT` |
| U5 | SN65HVD232D（SO-8，丝印 VP232） | CAN 收发器。**不耐热，任同学建议用烙铁焊**（07 集 [03:42]） |
| R3、R8 | 0.1Ω（1206） | 电机电流采样电阻，**别和 0Ω 的 R20 混了**（都是 1206，丝印 R100 和 000 要看清） |
| C29~C34 | 10µF/50V（1206） | 24V 滤波 |

**SO-8 烙铁焊法**（拖焊或点焊都行，引脚间距 1.27mm，不难）：
1. 板子正面朝下夹在 T6 夹具上，**正面的元件不要压到桌面**
2. 先给**一个角的焊盘**上一点锡
3. 用镊子把芯片放好、对齐 1 脚，烙铁熔化那一点锡，先固定一个脚
4. 检查 8 个脚是不是都正好压在焊盘上（不对就重新熔化调整），再焊**对角**的那个脚
5. 剩下的脚：涂一点助焊剂，烙铁带一点锡逐个点焊。烙铁约 **320–340℃**，每个脚 1–2 秒
6. 检查相邻引脚有没有连锡

### 阶段 ④ 插座 P1、P2、P3（烙铁）
- 3 个都是 ZH1.5 6P 直插座，从正面插入，在背面焊
- 插座要**贴紧板子、摆正**，插口方向对照丝印框。可以先焊一个脚，看一下歪不歪，再焊其余的
- 焊点要饱满，但不要让锡流到插座的塑料里面

### 阶段 ⑤ 最后：S1 拨码开关、K1/K2 按键（烙铁）
**为什么放到最后**：任同学原话，前面工序会用很多松香，**松香渗进微动开关会把它粘住**，开关就失效了，表现是**电机不能自动校准**（06 集 [22:17]）。拨码开关同理。
- 助焊剂**尽量少用**，焊完**不要用洗板水泡**它们
- 拨码开关的塑料怕热，烙铁每个脚点一下就走
- 焊完用蜂鸣档检查：按下 K1/K2 时，两个焊盘之间**要响**，松开**不响**。拨码开关每一位拨到 ON 时对应的脚要导通

## 六、Motor-35 板：和 42 板不一样的地方（照图 [Motor35分阶段焊接图.png](Motor35分阶段焊接图.png)）

35 板的物料和 42 板几乎一样（少了 C14、C35、T1、R16、R17、C26，10µF/50V 只有 C29~C32 四颗），但**电源链有一半在背面**，所以顺序要调整：

### 推荐顺序（流程 B；用流程 A 的话，按第四节做，第一次上电同样先用 9V）
1. **加热台（正面，只上一次）**：正面**除了 U3、U1、U2 三颗芯片**以外的所有元件。包括电源部分（D2、D3、D4、U6、L1、R13、R14、R15、C15~C20、C11）、所有 0402、Y1、LED。K1/K2/S1/插座照旧放到最后
2. **烙铁（背面电源）**：**D1**（SS54，注意极性）、**R20**（0Ω 1206）、**U7**（LP2992）、**C21、C22**（0402）
   - 0402 用烙铁焊：先给一个焊盘上锡，镊子夹着电容推过去焊一头，再焊另一头
3. **第一次上电**：红线焊在 **D1 的正极焊盘**（背面，没有色环那头），黑线焊在 **R20**。测 **5V 测 C19 两端**（正面），**3.3V 测 T2 或 C22**（背面）。标准和排查方法同 42 板
4. **热风枪（正面芯片）**：U3、U1、U2。这时背面已经有元件了，**不能再用加热台**
   - 按任同学的参数：**300℃ 左右、最低风量**，先绕着芯片周围大范围预热，再集中加热芯片，风嘴垂直
   - TB67 超过约 350℃ 就会烧（03 集 [23:01]），**温度不要往上调**
   - STM32 也可以用烙铁拖焊：对齐后先焊两个对角固定，涂助焊剂，烙铁带锡沿一排引脚拖过去，再用吸锡带清理连锡
5. **烙铁（背面其余）**：U8 MT6816、U5 CAN、C24、C25、R3、R8、C29~C32
6. 插座 P1/P2/P3 → 最后 S1、K1、K2

> 35 板用流程 A 更省事：正面一次回流后，背面电源部分（D1、U7、R20、C21、C22）和其余背面元件一起用热风枪或烙铁焊。注意 U7（LP2992）正对着正面的 ME3116 那一片电源电路，热风枪只局部吹，时间要短。

### 35 板特有的坑
- **P2（右边）和 P3（左边）长得一模一样**，都是侧面的 6P 插座。**P3 是下载口**，24V 线插到 P3 上就会烧板（任同学：「24V 插到 MCU 烧录口，烧主控加 CAN 芯片加一串」）
- K1/K2 在板子左边缘，按键会伸出板外一点，焊的时候按键的按压面要朝外

## 七、焊完之后：通电和烧录测试

### 1. 端口定义（V1.01，来自 `dummy_boards_manual.pdf` 和原理图）
| 插座 | 定义（原理图引脚 1→6） |
|---|---|
| P1 / P2（42 板在上边缘；35 板 P1 在上边缘、P2 在右边） | `+24V`、`+24V`、`CAN_L`、`CAN_H`、`GND`、`GND`。P1 和 P2 完全并联（一进一出） |
| P3（下载口，42 板在左边缘；35 板在左边） | `GND`、`SWCLK`、`SWDIO`、`GND`、`UART_TX`、`UART_RX` |

⚠️ **以上是原理图的引脚编号，不一定等于你从插座左边数过去的顺序**。上电前**用万用表蜂鸣档**确认：哪个孔和 D1 正极相通，哪个就是 +24V；哪个和 R20 相通，哪个就是 GND。Ryan 的 BOM 备注里也提到，V1.0.0 和 V1.0.1 的 6P 引脚顺序不一样，**线序不要照搬别人的**。

### 2. 整板上电（还是用稳压电源）
- 24V，**限流 0.10A**，从 P1 进电。可以用一根 ZH1.5 6P 线加一块空 PCB 焊个插座做转接（任同学的思路：空板上装个插头就能给驱动板供电）。**每根线接到哪个脚，都要先用万用表确认**
- 正常现象：C.V 灯亮，电流很小（没烧录程序的 STM32 只耗几 mA），T1 ≈ 5.2V，T2 = 3.3V
- 用手摸一下 TB67、ME3116、LP2992，**都不应该发烫**

### 3. 烧录
- ST-Link 只接 3 根线：**GND、SWDIO、SWCLK**，对应 P3 的引脚（按上表，用万用表确认）
- 烧录前先用 STM32CubeProgrammer 连接芯片，**确认 Flash 是 128KB**（你采购表里的提醒：C8T6 打磨改标成 CBT6 的假货很多）
- 42 板固件：`<V2>/2.Firmware/dummy-42motor-fw`，你已经在 Linux 上编译过，产物在 `<V2>/2.Firmware/build/motor42-baseline/`
- 35 板固件在当前工具链下很可能编译不过（索引第五节第 21 条），需要先修补

### 4. 不接电机也能验证的现象
烧录成功后，按 [焊接要点清单](任同学视频字幕/焊接要点清单.md) 第六节：**未校准状态下，一个 LED 常亮、另一个闪烁**。看到这个现象，就说明单片机、晶振、电源、固件都正常。校准需要装上电机和径向磁铁，以后再做。

### 5. S1 拨码开关
前 3 位（ID0/ID1/ID2）设置 CAN ID，对照表见 `dummy_boards_manual.pdf` 第 3 页。第 4 位是 120Ω 终端电阻开关。每块板设不同的 ID，**装机前贴个标签**，写上它是哪个关节、ID 是多少。

## 八、故障排查速查

| 现象 | 先查什么 |
|---|---|
| 上电 C.C 灯亮、电压掉下去 | 短路。断电，测 24V–GND、5V–GND、3.3V–GND，哪组短路就查哪一段；最常见的是芯片引脚连锡和电容焊歪 |
| 有 24V，没有 5V | D3/D4 焊反（任同学的经验）、U6 方向、L1 虚焊 |
| 5V 接近 24V | **R13 开路，马上断电**。这时 LP2992 很可能已经坏了，3.3V 那一路的芯片也要检查 |
| 5V 只有 1V 左右 | R13 和 R14 对调了 |
| 有 5V 没有 3.3V | U7 方向或虚焊，C21/C22 短路 |
| ST-Link 连不上 | **先测 3.3V**（任同学：LED 灯在 5V 下也会亮，灯亮不代表 3.3V 正常）；再查 SWDIO/SWCLK 有没有接反、STM32 引脚有没有连锡 |
| 能烧录但电机抖动、不能校准 | TB67 过热损坏、R3/R8 虚焊、K1 被松香粘住、MT6816 没焊正（任同学） |
| 编码器没有读数 | MT6816 虚焊或没焊正；装机时编码器和磁铁之间要留约 5mm；磁铁必须**径向充磁** |
| CAN 不通 | U5 虚焊或过热损坏；CAN_H/CAN_L 线序；终端电阻拨码 |

## 九、⚠️ 我从文件里查出来的额外风险

### 1. C27、C28 是 16V 电容，却接在 24V 上
- 原理图：C27、C28（0.1µF，在两颗 TB67 旁边）一端接 VCC（24V），另一端接 PGND
- 你买的 0.1µF 是 **FCC0402B104K160AT，耐压 16V**。全板 19 颗 0.1µF 用的都是它
- 两份原 BOM（Ryan 和任同学）也是 16V 的，他们这么做出来能用，所以**不是必须改**
- 但 24V 已经超出额定电压，电机工作时还会有尖峰。陶瓷电容坏的时候通常是**短路**，会直接把 24V 短到地
- **建议**：补买十几颗 **0402 100nF 50V（X7R）**，只换 C27、C28 这两个位置（每块板 2 颗 × 6 块 = 12 颗），花不了几块钱

### 2. 220µF 电解电容换成 35V：没有负面影响
- 采购表里你把 220µF 换成了 **35V、D8×L10.2mm**（耐压从 25V 提到 35V，这个换得对，24V 用 25V 余量太小）
- 封装名 `BD8.0-L8.3-W8.3` 里的 L8.3/W8.3 是**底座的长和宽**，不是高度；φ8 直径和焊盘完全匹配
- φ8×10.2 正是 220µF 贴片电解的标准尺寸，原作者用的 Nichicon 25V 款也是 φ8 规格。真正矮一截的是 Ryan 表里的 φ6.3×7.7（C2918361），那颗和焊盘不匹配。装外壳时顺手看一眼是否顶盖即可

### 3. 拨码开关和关键芯片零备件
见第一节。焊坏一个 S1 就要补货，**烙铁不要在拨码开关上停留太久**。
