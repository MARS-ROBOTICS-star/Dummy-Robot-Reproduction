## 一、当前结论

Dummy V2 的 7 块 PCB（Motor-42 ×3、Motor-35 ×3、REF ×1）均已完成焊接。当前有 5 块电机板可继续使用，42-3 和 REF 仍是硬件阻塞项：

- 42-1、42-2：上电和烧录均通过，但板上仍是 CAN 死锁修复前的固件，需要重烧。
- 35-1、35-2、35-3：上电、烧录和 LED 现象均已通过。
- 42-3：一次 24 V 误接损坏 U5（CAN）和 U3（STM32F103），等待一起更换。
- REF：U3、C20 更换后 3.3 V 能恢复，但冷启动仍可能进入 CC；U12 发热，保持复位时 VCAP 仍为 1.71 V，明显高于 STM32F405 的正常 1.20–1.32 V，当前禁止长时间上电。

实际进度已经超过 2026-09-29 路线图中的“尚未有硬件”快照，但还没有完成单电机闭环、两板 CAN 联调或整机六轴验收。现阶段应先把 42-3 和 REF 修到稳定，再进入电机和总线联调。

## 三、REF 当前故障链

### 1. 已经确认并处理过的问题

- Type-C 座 J1 内部 D+ 与 CC1 短路：J1 已更换，短路消失。
- CAN 收发器 U11（SN65HVD232DR）接收输出长期为低：抬起第 4 脚后 CAN1 初始化可以通过，STM32 USB 曾正常识别为 COM10。U11 仍需更换；当前 CAN 不能接收。
- 未接电机板时，REF 固件在 dummy.Init() 的 CAN 发送中永久等待：源码已临时注释该调用，但板上还需重烧对应新固件。

### 2. 2026-11-03 新出现的 3.3 V / VCAP 问题

- P1 输入 9 V、限流 0.1–0.3 A 时曾进入 CC，输入掉到约 4–5 V，C10 不能稳定到 3.3 V。
- 拆下 L2 后，5.2 V 前级恢复正常，问题被隔离到 U3 / L2 / 3V3 负载侧。
- 已更换 U3（SY8089A1AAC）和 C20；无 L2 备件，因此回装旧 L2。
- 首次回装后 C10 恢复 3.3 V，但 U12（STM32F405）明显发热；后续冷启动仍出现 CC、C10 约 2.87 V。
- 保持 C36 / NRST 为低时，电源由 CC 恢复 CV，C10 恢复 3.3 V；松开复位后仍能保持 CV。这说明当前不是持续性 3V3 硬短路，冷启动瞬态、旧 L2 和 U12 启动状态均需继续排查。
- 在复位保持、C10 已稳定 3.3 V 时，C34、C35 均为 1.71 V。该值不能由程序负载解释，VCAP 外围或 U12 内部稳压器存在异常。
- U12 已重新拖焊，现象未消失。断电蜂鸣不能单独证明 VCAP 与 3V3 外部短接，因为芯片内部稳压器也可能形成万用表可检测的通路。

### 3. REF 下一步顺序

1. 不长时间上电，不提高限流，不升到 24 V。
2. 更换 L2。原件为 TDK TFM252012ALTA2R2MTAA；可用的淘宝替代候选为 APH252012C2R2MP01（2.2 µH、2520、DCR ≤65 mΩ、Irms 2.7 A、Isat 3.3 A）。低电流的 NLV25T 2.2 µH 不可用。
3. 断电确认 C34、C35 接地可靠；修复时按 STM32F405 官方要求改用 2.2 µF、X5R/X7R、≥6.3 V、0402。
4. 如果换 L2、确认 VCAP 电容后，保持复位上电仍为 1.71 V，再拆 U12 做空焊盘隔离，不能直接盲换。
5. 修复合格标准：9 V、0.2–0.3 A 限流，保持复位时 C10 = 3.3 V，C34/C35 = 1.20–1.32 V，电源保持 CV，U12 不迅速发热。
6. 电源稳定后再换 U11、重烧 REF 新固件、验证 USB/OLED/CAN。
