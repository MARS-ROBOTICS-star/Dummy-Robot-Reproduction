## 〇、开始前：工具、规矩、对照法

### 0.1 工具

| 工具 | 用途 |
|---|---|
| 万用表（**细表笔**） | 蜂鸣档、电阻档、**二极管档**、直流电压档。四个档都要用 |
| KUAIQU 30V 稳压电源 | **全程用它，不要用 24V 适配器**。必须能限流 |
| 鳄鱼夹线 ×2、细导线 | 焊临时供电引线；一根表笔夹在 GND 上，可以单手测 |
| ST-Link V2 + 杜邦线 | 烧录口测试 |
| 放大镜 / 手机微距 | 看焊点 |
| Type-C 数据线 | REF 板 USB 测试（**要能传数据的线**，不是只能充电的线） |
| 美纹纸、记号笔 | 给板子编号：**42-A / 42-B / 42-C / 35-A / 35-B / 35-C / REF** |

### 0.2 四条规矩

1. **断电测完再上电**。断电那一节里有任何一项不通过，就不上电
2. **第一次上电永远是：限流 + 低电压 + 慢慢升**。不要一上来就 24V
3. 一只手拿表笔，另一只手**放在电源的 OUTPUT 键上**。看到电流突然变大、C.C 灯亮、冒烟、有焦味，马上关
4. 测量时表笔不要滑。一滑就可能把相邻两个脚短在一起，带电时这比焊错还危险。**带电时尽量测电容、电阻的两端，不要直接戳芯片引脚**

### 0.3 对照法（你有 3 块同型号板，这是最大的优势）

断电时测的「对地电阻」「二极管档读数」，绝对值和你的万用表型号有关，我给不出准确的标准值。但是**三块同型号的板子，同一个测点的读数应该差不多**。

- 三块都差不多 → 正常
- 两块差不多，一块明显偏离（比如低了一半，或者是 0） → **偏离的那块有问题**，去查那一路
- 每次测完都填进第七节的记录表

### 0.4 万用表三种读法

| 档位 | 怎么测 | 读数含义 |
|---|---|---|
| **蜂鸣档** | 两点之间 | 响 = 电阻很小（一般 < 30~50 Ω）。测电源对地时**「嘀」一下就停**，那是电容在充电，**不算短路**；**一直响**才是短路 |
| **电阻档** | 电源轨对 GND | 读数会**慢慢往上爬**（大电容在充电），等它稳定或者爬到很大再读。< 50 Ω 基本就是短路 |
| **二极管档** | **红表笔接 GND，黑表笔接电源轨**（反着接） | 读到的是芯片内部保护二极管的压降，一般 **0.3~0.7 V**。读到 **0.000~0.05 → 短路**。这是维修师傅最常用的「对地值」 |

## 一、⚠️ 这次解析原理图新发现的 5 件事（先看）

### ① REF 板灯环口的两颗 0 Ω 是 **R27 和 R29**，只能焊 R29

任同学字幕里先后说过「R27/R28」「R27/R29」「R7/R29」，原来的笔记标了「编号不要信字幕」。现在原理图解析出来了：

| 位号 | 一端 | 另一端 | 要不要焊 |
|---|---|---|---|
| **R27**（0 Ω，正面左边缘） | P3 第 1 脚（灯环电源） | **3.3 V** | ❌ **不焊** |
| **R29**（0 Ω，紧挨 R27） | P3 第 1 脚 | **5 V**（VCC_5V） | ✅ 焊（WS2812 要 5 V） |
| R28 | — | — | 跟这件事无关，是 NRST 的 10 K 上拉 |

**两颗都焊了 = 3.3 V 和 5 V 短在一起**，上电后 STM32、ESP32、IMU 全部吃 5 V。第四节第 4 步专门测这个。

### ② REF 和电机板的原理图里，CAN_H / CAN_L 的引脚号是**反的**

| 6P 座第几脚（原理图编号） | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| **电机板 P1 / P2** | +24V | +24V | **CAN_L** | **CAN_H** | GND | GND |
| **REF 板 P1** | +24V | +24V | **CAN_H** | **CAN_L** | GND | GND |

24 V 和 GND 两边一致，**CAN 的 3、4 脚对调了**。可能是插座封装的引脚编号和实物方向有关，也可能真是设计如此，原理图本身判断不了。
**不要猜，用万用表实测**：第六节的方法是隔着线束量 REF 的 U11 第 7 脚到电机板 U5 第 7 脚，这两个都是 CANH，必须导通。CAN 接反不会烧板，但总线完全不通。

### ③ REF 的「9 V 首次上电」保护**不够用**，要多一步

电机板的 3.3 V 用的是 LDO（LP2992），能扛十几伏，所以 9 V 首次上电那一招在电机板上是安全的。
REF 的 3.3 V 用的是**开关电源 SY8089**，反馈电阻是 **R33（100 K，上臂）/ R35（22.1 K，下臂）**，都在背面：

- **R33 虚焊** → SY8089 以为输出太低，把 3.3 V 推到等于输入，也就是 **5.2 V**。这时 STM32F405、ESP32、MPU6050、nRF24 会一起烧
- 这和输入是 9 V 还是 24 V 无关，所以 9 V 那一招挡不住

对策：REF 第一次上电**先从 5 V 轨灌 3.5 V**。这时就算 R33 虚焊，3.3 V 这一路最多也只有 3.5 V，所有芯片都扛得住。详见第五节。

### ④ REF 的 Type-C：**正插、反插接的是两颗不同的芯片**

| Type-C 座的脚 | 接到 |
|---|---|
| A6 / A7（D+ / D−，A 面） | **STM32F405 的 USB**（PA12 / PA11） |
| B6 / B7（D+ / D−，B 面） | **CP2102**（USB 转串口，再接 ESP32） |
| VBUS | **只给 CP2102 供电** |

一根普通的 USB 线里只有一对 D+/D−，所以**插头翻个面，电脑看到的就是另一颗芯片**。另外：
- **USB 不能给整板供电**。STM32、ESP32 的 3.3 V 只能从 24 V 来。只插 USB 时，只有 CP2102 在工作
- 插上 USB 电脑没反应时，先翻个面再插一次，不要急着判定坏了

### ⑤ 两种板的 LED 意义不一样

- **REF 的 LED1**：3.3 V → LED → R18（2 K）→ GND，是**电源指示灯**。一上电就亮（3.3 V 过压时也会亮，所以亮了不代表电压对）
- **电机板的 LED1 / LED2**：阴极接地，阳极经 R11 / R18 接单片机。**没烧固件之前不亮，这是正常的**

## 二、电机板（42 / 35）：断电万用表测试

> 6 块板全部做完这一节再开始上电。每块大约 30–40 分钟。

### 第 1 步：目检（放大镜）

| 查什么 | 位号 | 正确的样子 |
|---|---|---|
| 芯片 1 脚 | U3（STM32）、U1/U2（TB67）、U5（CAN）、U8（MT6816）、U6（ME3116）、U7（LP2992） | 芯片圆点 / 斜边对准丝印的点或缺角 |
| 二极管方向 | D1（SS54）、D3 / D4（1N5819） | 色环（负极）对准丝印的 K 端 |
| 电解电容 | C11（42 板还有 C14） | 外壳顶部黑色那边（负极）不对着丝印 + |
| 晶振 | Y1 | 印 **12.000**，不是 8.000 |
| 反馈电阻 | R13（10 K）、R14（1.8 K） | 两端都有焊锡、没有立碑、**没有对调**（丝印 103 和 182） |
| 采样电阻 vs 0 Ω | R3 / R8（R100）、R20（000） | 别装混 |
| TB67 | U1、U2 | 平贴在板上，没有被底部焊盘的锡顶起来，8 个脚都有锡 |
| 插座 | P1 / P2 / P3 | 贴平，插针没歪 |

### 第 2 步：三组电源对地不能短路（蜂鸣档 + 电阻档）

黑表笔接 **GND**。GND 可以取：R20 的任意一端、P3 第 1 脚或第 4 脚、任意电容的接地端。

| 测哪里 | 42 板测点 | 35 板测点 | 合格 |
|---|---|---|---|
| 24 V 母线 VCC | C11 正极 / D1 色环那一端 | 同左（D1 在背面） | 不长响；42 板电阻 **≈ 11 kΩ**（R16 + R17 分压电阻对地）；35 板没有 R16/R17，读数会**一直往上爬到几百 kΩ 以上** |
| 5 V（VCC_5V） | **T1** | **C19** 两端 | 不长响；电阻 **≈ 几 kΩ ~ 11.8 kΩ**（R13 + R14 = 11.8 kΩ 是上限） |
| 3.3 V | **T2** | **T2**（背面，P1 朝上看：C21/C22 正上方的小圆点，左下是 U7、右上是 MT6816；看不清就测 C22 两端） | 不长响；三块同型号板读数要接近 |
| 24 V 入口 VCC_IN | P1 第 1 脚 | 同左 | 同上 |

再用**二极管档反接**（红 GND、黑电源轨）测 5 V 和 3.3 V，读数填进记录表，三块比一比。

### 第 3 步：地线、0 Ω 电阻都要通（蜂鸣档，应该响）

原理图里电机板有**三种地**：GND（信号地）、PGND（功率地，P1/P2 的地脚、TB67 底部焊盘都接它）、AGND（模拟地）。它们靠 0 Ω 电阻连在一起，**漏焊一颗，整板就不共地**。

| 两点 | 靠哪颗电阻连通 | 应该 |
|---|---|---|
| P1 第 5 脚（PGND） ↔ P3 第 1 脚（GND） | **R20**（1206） | 响 |
| U3 第 8 脚（VSSA） ↔ GND | **R22**（0402） | 响 |
| U3 第 9 脚（VDDA） ↔ T2（3.3 V） | **R21**（0402） | 响 |
| P1 第 1、2 脚 ↔ P2 第 1、2 脚 | 板上走线（两个座子并联） | 响 |
| P1 第 3 脚 ↔ P2 第 3 脚，P1 第 4 脚 ↔ P2 第 4 脚 | 同上 | 响 |

### 第 4 步：芯片相邻引脚（蜂鸣档，不应该响）

最重要的是**电源脚和地脚挨在一起的那几对**，这里一连锡，上电就是 3.3 V 对地短路：

| 芯片 | 必测的相邻脚 | 说明 |
|---|---|---|
| U3 STM32F103（LQFP-48） | **8–9**（VSSA/VDDA）、**23–24**、**35–36**、**47–48**（VSS/VDD） | 这 4 对必须不响。然后把 48 个脚逐对全测一遍 |
| U3 | 第 44 脚 BOOT0 ↔ GND **应该是 10 kΩ**（R9 下拉） | 读到 0 Ω 说明 BOOT0 和旁边的地连锡了 |
| U3 | 第 7 脚 NRST ↔ 3.3 V **应该是 ≈ 10 kΩ**（R10 上拉） | |
| U1 / U2 TB67H450 | **第 5 脚（VCC，24 V）↔ 第 1 脚 / 底部焊盘（PGND）** | 不响。8 个脚逐对测 |
| U5 SN65HVD232 | **2–3**（GND/VCC）、**6–7**（CANL/CANH） | 不响（6–7 之间见第 6 步） |
| U8 MT6816 | 8 个脚逐对测 | 不响 |
| Y1 晶振 | 4 个焊盘之间 | 不响 |

> 测到响，先看原理图这两个脚是不是本来就连在一起（比如都是 GND），不是的话才是连锡。

### 第 5 步：P3 烧录口引脚（蜂鸣档确认，不要只信编号）

| P3 第几脚 | 定义 | 怎么确认 |
|---|---|---|
| 1 | GND | 和 R20 相通 |
| 2 | SWCLK | 和 U3 **第 37 脚**相通 |
| 3 | SWDIO | 和 U3 **第 34 脚**相通 |
| 4 | GND | 和 R20 相通 |
| 5 / 6 | UART TX / RX | 暂时用不上 |

确认完拿记号笔在板子背面写上 **「P3=烧录，别插 24V」**。35 板的 P2 和 P3 长得一样，最容易插错。

### 第 6 步：开关和按键

| 测什么 | 方法 | 合格 |
|---|---|---|
| K1 | 蜂鸣档测 K1 两个焊盘（一端是 GND，另一端接 U3 第 25 脚 PB12） | 按下响、松开不响。**按着不放也一直不响 = 被松香粘住了** |
| K2 | 同上（接 U3 第 20 脚 PB2） | 同上 |
| S1 第 1~3 位（ID0/ID1/ID2） | 拨到 ON，测 U3 第 29 / 30 / 31 脚对 GND | ON 响，OFF 不响 |
| S1 第 4 位（终端电阻） | **电阻档**测 P1 第 3 脚 ↔ 第 4 脚（CAN_L ↔ CAN_H） | ON ≈ **120 Ω**（R12）；OFF 是高阻（几十 kΩ 以上，是 CAN 芯片的输入阻抗） |

## 三、电机板：上电测试

> 先只做 **1 块 42 板**，从头到尾做完（包括烧录）。确认没问题再批量做剩下 5 块。

### 3.1 怎么接电

> 测点位置图：[Motor42上电测点图.png](Motor42上电测点图.png)、[Motor35上电测点图.png](Motor35上电测点图.png)（35 板没有 T1，5 V 量 C19 上端；3.3 V 量正面 C10 左端或背面 T2）。P1 / P2 / P3 都是 **ZH1.5（1.5 mm 间距）** 插座，杜邦线插不进去，要用 ZH1.5 单头线转接，或者直接焊临时线。

- ⚠️ **教训（42-3，2026-11-01）**：用 P1 插线供电时 CAN 线头碰到了 +24V，U5（CAN 芯片）被打坏，3.3 V 被倒灌到 3.79 V，随后 U5 击穿把 3.3 V 对地短路。**测试用的插线，先把第 3、4 脚（CAN）两根从插头里挑出来或齐根剪掉**，只留 +24V 两根、GND 两根
- **方法 1（推荐）**：P1 已经焊好了，就从 P1 进电。用一根 6P 线加一块空 PCB 焊个插座做转接，**每根线接哪个脚先用万用表确认**（第 1、2 脚 = +24V，第 5、6 脚 = GND）
- **方法 2**：临时引线。红线焊在 **D1 正极**（没有色环那一端，靠近 P1），黑线焊在 **R20** 任意一端

稳压电源设置限流（先**不接板子**）：电压先随便调到 5 V，用一根导线把输出正负短接，转电流旋钮到 **0.10 A**，拆掉短接线。然后把**电压旋钮转到 0**。

### 3.2 缓升法第一次上电（核心步骤）

万用表**黑表笔夹在 GND 上，红表笔一直按在 T1**（35 板按在 C19 的 5 V 端）。然后：

| 输入电压 | 看什么 | 正常 | 异常就马上关输出 |
|---|---|---|---|
| 0 → 4 V | 电流 | 几乎是 0 | 电流一下子到了 0.1 A、C.C 灯亮 → 短路 |
| 4 → 6 V | T1 | 开始出现电压，慢慢升到 **≈ 5 V** | — |
| 6 → 9 V | **T1 不再跟着涨** | 稳定在 **≈ 5.2 V**（0.8 V × (1 + 10 K / 1.8 K) = 5.24 V） | **T1 一直跟着输入涨 → R13 开路**，马上关 |
| 9 V 停住 | 测下面的全套电压表 | — | — |

**为什么这样做**：R13（反馈上臂）一虚焊，5 V 这一路就会跟着输入走。慢慢升压，看到 5 V 不稳住就停，5 V 这一路最多也就到 6~8 V。电机板 5 V 上只挂了 LP2992（能扛 16 V）和 10 V 耐压的电容，**什么都不会坏**。

### 3.3 9 V 下的全套电压表（黑表笔接 GND）

| 测点 | 是什么 | 应该是 | 不对先查 |
|---|---|---|---|
| D1 正极 / P1 第 1 脚 | 输入 | = 电源显示值 | 线没接好 |
| D1 负极 / C11 正极 | VCC 母线 | 比输入低 **0.3~0.45 V** | 0 V：D1 焊反或虚焊 |
| U6 第 5 脚 / C20 | ME3116 输入（过了 D4） | 比 VCC 再低 ≈ 0.3 V | 0 V：D4 焊反 |
| **T1**（35：C19） | 5 V | **5.1~5.3 V** | 0 V：D3/D4 焊反、U6 方向、L1 虚焊；≈ 0.9 V：R13/R14 对调 |
| **T2** | 3.3 V | **3.25~3.35 V** | 0 V：U7 方向 / 虚焊；有 5 V 没 3.3 V：C21/C22 短路 |
| U3 第 9 脚 / C23 | VDDA | 3.3 V | 0 V：R21 没焊 |
| U3 第 7 脚 / C9 | NRST | ≈ 3.3 V | 0 V：C9 短路或 NRST 连锡 |
| U3 第 44 脚 | BOOT0 | **0 V** | 3.3 V：R9 没焊或和 VDD 连锡 |
| C26 不接地的那端（**42 板**） | 24 V 采样（R16 / R17 = 10 K / 1 K） | **输入 × 1/11**：9 V 时 ≈ 0.78 V，24 V 时 ≈ 2.1 V | 比例不对：R16 / R17 焊错 |
| U5 第 7 脚 / 第 6 脚 | CANH / CANL | 两个都 **≈ 2 V 左右**，而且**两者几乎相等**（总线空闲） | 一个是 0 V 或 3.3 V：U5 虚焊或 CAN 脚连锡 |
| 电流表 | 整板电流 | **≈ 0.01~0.03 A**（没烧固件、没接电机） | > 0.05 A：有东西在漏电，摸一摸哪颗芯片热 |

### 3.4 升到 24 V，复测

- 9 V 一切正常，慢慢升到 **24 V**，限流保持 0.10 A
- T1、T2 应该和 9 V 时**一模一样**（开关电源输出不随输入变）
- 24 V 时的电流**比 9 V 时还小**，这是对的（开关电源输入电压高、电流就小）
- **放 3 分钟，用手指摸**：U6（ME3116）、U7（LP2992）、U1/U2（TB67）、U3 都**不应该烫手**。U6 微温可以接受

### 3.5 ST-Link 识别芯片

1. **断电**接线：ST-Link 的 **GND → P3 第 1 脚，SWCLK → P3 第 2 脚，SWDIO → P3 第 3 脚**。ST-Link 的 3.3 V **不要接**（板子自己从稳压电源供电，两路电源会打架）
2. 上电 24 V（直接 24 V 即可，这块已经验证过了）
3. 打开 STM32CubeProgrammer → ST-LINK → Connect。连不上就把 Mode 改成 **Under reset**，Reset mode 改成 **Hardware reset**（如果 ST-Link 的 RST 线没接，就用 Software reset）
4. 看右下角的信息：

| 项目 | 应该是 |
|---|---|
| Device | STM32F101/F102/F103 **Medium-density** |
| Device ID | **0x410** |
| Flash size | **128 KB**（显示 64 KB = 拿到了打磨改标的 C8T6） |

### 3.6 烧录固件，看 LED

- 固件：`<V2>/2.Firmware/build/motor42-baseline/Ctrl-Step-STM32-fw.hex`（你在 Linux 上编出来的）
- **35 板也可以先烧这个做冒烟测试**：索引第八章查过，42 和 35 固件只差一个参数 `dce_kp`（200 vs 195），引脚、时钟、CAN 全部一样。正式装机再换成 35 的固件
- 烧完断电重新上电。正常现象（任同学视频）：**一个 LED 常亮、另一个闪烁**（未校准状态）
- **这时不要按 K1 / K2**。没接电机时触发校准会失败，现在没必要
- 电流应该还是几十 mA 以内

**到这里，这块板的硬件就算过关了**：电源、单片机、晶振（没有晶振 LED 闪烁频率会不对，CAN 也会失败）、烧录口都是好的。MT6816 和 TB67 要等装上电机、磁铁之后才能测（校准那一步）。

### 3.7 批量测剩下 5 块

第一块全部通过后，剩下 5 块每块都**完整走一遍 3.2~3.6**，不要因为第一块没问题就跳过缓升法。R13 虚焊是随机的，不是系统性的。

## 六、联调前：线束和 CAN 总线测试

> 7 块板各自都通过之后再做这一节。**所有测试都在断电状态下进行。**

### 6.1 每根 6P 线单独测

ZH1.5 的 6P 成品线有「同向」和「反向」两种，一种是 1 对 1，另一种是 1 对 6（整排倒过来）。**倒过来的那种会把 24 V 送到对面板子的 GND**，后果就是任同学说的「一路烧过去」。

> ⚠️ **不要按「同向 / 反向」这个名字买线、装线**：资料里两种说法正好相反。`Cable_connection.pdf`、Ryan BOM 说「REF→J1 用同向线，电机板之间用反向线」；任同学第 15 集说「REF→J1 用反向线，驱动板之间用同向线」。**只认万用表**。

每根线都要测：

1. 一根线两头插在两块板上（比如 REF 的 P1 和 42-1 的 P1）
2. 蜂鸣档测：

| 一头 | 另一头 | 应该 |
|---|---|---|
| REF 的 **D2 正极**（没色环那端 = P1 的 +24V） | 42 板的 **D1 正极**（没色环那端） | **响** |
| REF 的 GND（C6 负极） | 42 板的 R20 | **响** |
| REF 的 D2 正极 | 42 板的 R20 | **不能长响！**长响就是线序倒了，立刻拔掉、标记作废 |
| **REF U11 第 7 脚（CANH）** | **42 板 U5 第 7 脚（CANH）** | **响** |
| REF U11 第 6 脚（CANL） | 42 板 U5 第 6 脚（CANL） | **响** |

> 不能拿 REF 的 C6 正极去对 42 板的 C11 正极：中间隔着 REF 的 D2 和 42 板的 D1 两颗二极管，线接对了也不会响。

如果 24 V 对了，但 CANH 对到了 CANL（第一节第 ② 条那种情况），这根线不会烧板，但 CAN 不通。要么换一种线序，要么在 REF 端把 3、4 脚的线对调。**最后以「U11 第 7 脚 ↔ U5 第 7 脚导通」为准**。

3. 电机板之间的线（P2 → 下一块板的 P1）也一样测：D1 正极 ↔ D1 正极、R20 ↔ R20、U5 第 7 脚 ↔ U5 第 7 脚都要响，D1 正极 ↔ 对面 R20 不能长响。电机板的 P1、P2 引脚完全一样，所以这几根线必须是**按脚号 1 对 1**

### 6.2 整条总线的终端电阻

CAN 总线只能在**最两头**各接一个 120 Ω：
- 一头是 REF（R24 焊上）
- 另一头是链路上最后一块电机板（J6），把 S1 上**控制终端电阻的那一位**拨 ON
- **中间的电机板，这一位全部拨 OFF**

**哪一位是终端电阻要先测出来**：原理图上终端电阻接在 S1 的第 4 号焊盘，但固件注释写的是「ID0 = Switch 4」，说明拨码开关**外壳上印的 1~4 很可能和焊盘号是反的**，也就是外壳上印「1」的那一位才是终端电阻。测法：断电，电阻档测 P1 第 3、4 脚之间，逐个拨每一位，**变成约 120 Ω 的那一位**就是终端电阻。

全部接好后，断电，电阻档测**任意一块板 U5 的第 6 脚 ↔ 第 7 脚**：

| 读数 | 含义 |
|---|---|
| **≈ 60 Ω** | 正确（两个 120 Ω 并联） |
| ≈ 120 Ω | 只接了一个终端 |
| ≈ 40 Ω 或更小 | 终端接多了（中间某块板的 S1 第 4 位没关） |
| ≈ 0 Ω | CANH 和 CANL 短路了，逐段拔线找 |

### 6.3 拨码 ID

ID 是二进制数，拨到 ON 的那一位记作 1。按固件注释，ID 的三位对应外壳上印的 **4 号（权重 1）、3 号（权重 2）、2 号（权重 4）**：

| 关节 | ID | 外壳 4 号 | 3 号 | 2 号 |
|---|---|---|---|---|
| J1 | 1 | ON | | |
| J2 | 2 | | ON | |
| J3 | 3 | ON | ON | |
| J4 | 4 | | | ON |
| J5 | 5 | ON | | ON |
| J6 | 6 | | ON | ON |

和群里说的 `0001`~`0110` 一致：从外壳 1 号读到 4 号，4 号在最右边，是最低位。**拨完烧固件、接上 REF 后，用上位机确认每块板的 ID 再装机**。设好之后贴标签：关节号 + ID。

### 6.4 7 块板一起上电

用稳压电源 **24 V、限流 0.5 A**，接到总线的 +24V / GND 上：REF 没有单独的电源口，24 V 只能从 6P 总线进来，可以在 REF→J1 那根线上并一对线出来接电源。总电流应该大约是各块板单独电流的总和（**≈ 0.1~0.2 A**，估算）。超过很多就逐块拔线排查。

## 八、故障速查

| 现象 | 最可能 | 怎么查 |
|---|---|---|
| 一上电 C.C 灯亮、电压被拉下去 | 某路电源对地短路 | 断电，三组对地逐一测；带电情况下可以用 0.1 A 限流让短路点慢慢发热，**手摸**哪颗元件热就是它 |
| 有 24 V 没有 5 V | D3/D4 焊反、U6 方向、L1 虚焊（REF：D4/D5、U8、L1） | 测 U6 第 5 脚有没有电压，没有是 D4 的问题 |
| 5 V 跟着输入涨 | **R13 开路**（REF：**R11**） | 马上断电，补焊 |
| 5 V 只有 ≈ 0.9 V | R13 / R14 对调 | |
| 电机板有 5 V 没 3.3 V | U7 方向 / 虚焊，C21/C22 短路 | |
| REF 3.3 V 等于 5 V 轨 | **R33 开路** | 第 A 步就能发现 |
| REF 3.3 V 是 0 | U3 方向、R34 没焊（ON/OFF 没拉高）、L2 虚焊 | |
| REF 3.3 V 和 5 V 一样高，而且换 SY8089 也没用 | **R27 被焊上了** | 第四节第 4 步 |
| ST-Link 连不上 | 3.3 V 不对；SWCLK/SWDIO 接反；NRST 连锡；BOOT0 不是 0 | 先量 3.3 V，再查 P3（REF 是 P2）的线 |
| 能连上但 Flash 显示 64 KB | 芯片是打磨改标的 C8T6 | 换芯片 |
| 电机板烧完固件 LED 不亮 | LED 焊反；晶振 Y1 不起振 | LED 用二极管档测正反 |
| REF 插 USB 电脑没反应 | 插头那一面接的是 STM32 | 翻面 |
| CP210x 有，但串口什么都收不到 | 24 V 没接（ESP32 没电）；ESP32 虚焊 | |
| CAN 线两头量不通 | 线序 / 第一节第 ② 条 | 以 U11-7 ↔ U5-7 为准 |
| 总线电阻不是 60 Ω | 终端电阻拨错 | 6.2 节 |
