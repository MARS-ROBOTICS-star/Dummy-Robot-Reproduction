## 一、这块板子是什么

- 一个圆环形 PCB：**外径 47.6 mm，内径 32.4 mm**，双层板
- 正面：**12 颗 WS2812B 灯珠（D1–D12）**，级联排成一圈
- 背面：**没有元件**，只有 3 个引线焊盘（丝印 `+` / 中间 / `−`）
- **板上没有电容、没有电阻、没有插座**。原理图和 PCB 里都只有这 12 颗灯（已核对，PCB 里只有 12 个封装）

所以这是全套资料里最简单的一块板，适合用来练手：只有一种元件，焊盘大，而且所有灯珠都在同一面，可以直接放加热台上回流。

## 二、元器件清单

| 物料 | 型号 / 规格 | 数量 | 来源 |
|---|---|---|---|
| RGB 灯珠 | **WS2812B-B/T**（Worldsemi，SMD5050-4P），立创编号 **C2761795** | 12（BOM 买了 15 颗，**建议多买 3–5 颗备用**） | `实际采购iBOM_Dummy整机.xlsx`、`Dummy_V2_BOM_Ryan_v1.1.xlsx` |
| 引线 | **ZH1.5mm 3Pin 端子线**，剪掉一头，直接焊到背面焊盘 | 1 根 | BOM「6pin 连接线」备注：其中一根是 LEDring 连接线 |
| PCB | LedRing（用 `led gaber.zip` 打样） | 1 片（打样一般给 5 片） | — |

自备耗材：锡膏（**推荐低温锡膏 Sn42Bi58**，见第四节）、助焊剂、焊锡丝、洗板水/无水酒精、尖头镊子、放大镜/手机微距、万用表、5V 电源（最好能限流）。

> 灯环在整机中是**选装**（索引第十三章：auk / V1.01 体系里没有这块板）。只想练手的话不影响主线。

## 三、焊之前必须搞清楚的两件事

### 1. 灯珠方向：缺角对准白色三角

我把 Gerber 的铜层做了连通性分析，**12 颗灯每一颗旁边的白色小三角，都正好挨着 GND 焊盘**（见示意图上的黑色焊盘）。

WS2812B 的引脚是：1 VDD、2 DOUT、3 **VSS(GND)**、4 DIN。灯珠封装表面有一个**缺角/标记角，通常标的是 GND 脚**。

所以放件规则是：**灯珠的缺角对准丝印三角**。

⚠️ **上件前一定要核对一遍**，因为不同批次、不同厂家的 5050 灯珠，标记角的定义不完全一样：
1. 打开立创 C2761795 的数据手册，看标记角对应的是哪个脚
2. 光板上用万用表蜂鸣档，一支表笔点背面 `−` 焊盘，另一支点任意一颗灯三角旁边的焊盘，**应该会响**，这样就确认了三角那里是 GND
3. 两边一致再动手。如果手册上标记角不是 GND，就按「GND 脚对准三角」来放，不要按缺角

**焊反的后果**：VDD 和 GND 接反，一上电这颗灯基本就坏了，而且数据链会在它这里断掉。

### 2. 数据链顺序（排查时要用）

数据从背面中间焊盘进入，然后按下面的顺序**顺时针**一颗传一颗：

```
D1 → D4 → D7 → D10 → D2 → D5 → D8 → D11 → D3 → D6 → D9 → D12
第1   第2   第3   第4    第5   第6   第7   第8    第9   第10  第11  第12
```

注意：**丝印编号不等于数据顺序**，比如第 2 颗是 D4，不是 D2。D1 在引线焊盘附近，编号更大的灯沿圆环顺时针往后排。

背面焊盘（**以丝印为准**）：`+` = +5V，中间 = DIN 数据，`−` = GND。

## 四、方案选择：用加热台回流（推荐）

灯珠全在正面、背面没有元件，所以加热台是最合适的工具：整块板受热均匀，灯珠在锡膏熔化后还会自己对正。

**锡膏推荐用低温锡膏（Sn42Bi58，熔点约 138℃）**。WS2812B 是塑料透镜，里面有 IC，比普通 LED 怕热，温度越低越安全。中温锡膏（Sn63Pb37，熔点 183℃）也能用，但需要更高的温度。

| 锡膏 | 加热台设定 | 说明 |
|---|---|---|
| 低温 Sn42Bi58 | **约 170–180 ℃** | 首选 |
| 中温 Sn63Pb37 / 有铅 | **约 210–220 ℃** | 不要长时间保温 |
| 无铅 SAC305 | 约 240–250 ℃ | **不推荐用在灯珠上** |

这些是经验设定值，加热台表面实际温度和显示值会有偏差，先拿一片空板试一下锡膏多久能化开。具体上限以 C2761795 数据手册里的回流曲线为准。

## 五、详细操作步骤

### 步骤 0：准备
1. 灯珠如果已经拆袋放了很久，WS2812B 容易受潮，回流时可能「爆米花」导致透镜开裂。可以先用加热台低温（约 60–70 ℃）烘几个小时。具体烘烤条件看数据手册里的 MSL/烘烤说明
2. PCB 用酒精擦一遍，去掉手指油污
3. 先测光板：万用表蜂鸣档测背面 `+` 和 `−`，**不应该响**。如果光板就短路，是板厂的问题，不要继续焊
4. 按第三节的方法确认 GND 焊盘位置

### 步骤 1：上锡膏（没有钢网）
1. 灯环没做钢网也没关系，焊盘约 1.1 × 1.0 mm，用针筒直接点就行
2. 每个焊盘点一小团，**大约占焊盘面积的一半**，共 48 个焊盘
3. **宁少勿多**。锡膏太多会在灯珠底下连锡（VDD 和 DOUT、GND 和 DIN 挨得很近），而且从外面看不到
4. 每颗灯的 4 个焊盘尽量点得一样多，不然灯珠会被拉歪或者立起来

### 步骤 2：放灯珠
1. 用镊子夹灯珠侧面，**不要夹透镜**（透镜很软，夹一下就会留痕）
2. **缺角（GND 标记）对准丝印三角**，透镜朝上
3. 轻轻放下，压一下就行，不用压到底
4. 12 颗都放好后**拍一张照片放大检查**，逐颗确认方向。这一步最重要，回流之后再改就要用热风枪返修了

### 步骤 3：加热台回流（分两段升温，不要直接放到高温上）
1. **预热段**：加热台设到约 **120 ℃（低温锡膏）/ 150 ℃（有铅锡膏）**，等温度稳定后，用镊子把板子**平放**上去（正面朝上）。保持约 **60–90 秒**，直到锡膏不再冒泡、冒烟明显变少
2. **回流段**：把加热台调到回流温度（低温锡膏 170–180 ℃ / 有铅 210–220 ℃），板子留在上面跟着升温
3. 观察锡膏：从灰色**突然变亮、变成液态**，同时灯珠会轻轻自己对正
4. **全部焊点变亮之后再等大约 10 秒**就取下来。不要放在上面一直加热
5. 取下时板子要保持水平，放到耐热垫上**自然冷却**。冷却之前不要碰灯珠，也不要吹风

> 为什么不直接放到 220 ℃ 上：冷板突然接触高温，锡膏里的溶剂会剧烈沸腾，把灯珠顶歪、溅出锡珠；受潮的灯珠也更容易「爆米花」开裂。预热这一段让溶剂先慢慢挥发、助焊剂先起作用，焊出来更干净，也更不容易连锡和虚焊。

### 步骤 4：检查焊点
1. 5050 封装的引脚从侧面看得到。用放大镜或手机微距逐颗检查，**4 个引脚都应该有亮的、往上爬的焊锡**
2. 如果有灯珠歪了或者立起来了：在加热台上重新加热，熔化后用镊子轻轻拨正
3. 用万用表查连锡：每颗灯珠的**相邻引脚两两测通断**，尤其是 VDD 和 GND
4. 最后再测一次 `+` 和 `−` 之间：**不能响**（这是任同学强调的那句「上电前必须查完连锡」）

### 步骤 5：清洗
用洗板水或无水酒精加软毛刷，把残留的助焊剂刷掉。注意不要用力刷透镜。

### 步骤 6：焊引线（背面 3 个焊盘，用电烙铁）
1. 烙铁约 **320–350 ℃**，先给 3 个焊盘各上一点锡
2. ZH1.5 端子线剪掉一头，剥线约 2 mm，线头先上锡
3. 把线头贴到焊盘上，烙铁一点就好，每个焊盘不超过 3 秒
4. **线色和功能的对应关系先别凭颜色猜**。REF 板上灯环接口的定义是 `GND`、`PWM`、`+5V`（来自 `6.Docs/Pins definations.pdf`），用万用表从端子头逐根测，确认每根线接到 REF 哪个脚，再焊到背面对应的焊盘：GND → `−`，PWM → 中间，+5V → `+`
5. 焊完之后用热熔胶或 UV 胶把线根部固定一下，防止拉扯时把焊盘扯掉

### 不用加热台的备选方案
- **热风枪**：按任同学的参数，**300 ℃ 左右、最低风量**，先吹整块板预热，再由近到远吹，风嘴垂直、离远一点。**不要对着透镜一直吹**，透镜会起泡、变黄
- **电烙铁**：5050 侧面引脚露在外面，可以先在一个焊盘上点锡，用镊子按住灯珠把这只脚焊上，校正位置后再焊另外 3 只脚。烙铁约 300–320 ℃，每只脚不超过 3 秒

## 六、通电测试

### 第一步：空载上电（只接电源，不接数据线）
1. 5V 电源，如果可以限流，先限 **100 mA**
2. 接 `+` 和 `−`，**灯不会亮，这是正常的**：WS2812B 没收到数据时保持熄灭
3. 电流应该很小（12 颗灯的静态电流加起来大概只有几 mA 到十几 mA）。**如果电流很大或者直接顶到限流值，说明有短路或者有灯焊反了**，马上断电

### 第二步：给数据点亮
需要一个能输出 WS2812 时序的 MCU。目前手上没有 Dummy 主控板，可以用身边的开发板：
- Arduino / ESP32：Adafruit_NeoPixel 或 FastLED 库，灯数设为 12，DIN 接任意 GPIO，**GND 必须和灯环共地**
- STM32（江协课程用的 F103 板子）：用 PWM+DMA 或 SPI 模拟时序（这是个不错的练手项目，以后 Dummy 主控点灯用的就是这个原理）

注意：
- 数据线上可以串一个 **330 Ω 左右的电阻**，保护第一颗灯
- 3.3V 的 MCU 驱动 5V 供电的 WS2812B，电平在临界区（高电平阈值约 0.7×VDD = 3.5V）。大多数情况下能用，不稳定的话可以把灯环电源降到 4.5V 左右，或者加一个电平转换
- 12 颗灯全白最大亮度时电流约 0.7 A。测试时**亮度先调低**，USB 口供电不太够

### 以后接 REF 主控板时
- REF 板上的 RGB 那一路需要 5V。任同学踩过的坑：**HD3 旁边那两颗 0Ω 电阻不能都焊**（一颗接 3.3V，一颗接 5V，两颗都焊会把 3.3V 和 5V 短在一起）。编号以原理图为准，详见 [焊接要点清单](任同学视频字幕/焊接要点清单.md) 第三节第 1 条
- 本地主控固件 `Core/Inc/main.h` 缺 `RGB_Pin`(PA3) 定义（索引第十二章），真要点亮时需要在 CubeMX 里把 PA3 配好

## 七、故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 一颗都不亮 | ① 先量 `+` 和 `−` 之间是否有 5V；② 是否共地；③ **第 1 颗（D1）** 的 DIN 或 VDD/GND 虚焊，或者 D1 焊反、已损坏；④ 数据线接到了 `+` 或 `−` 上 |
| 前 N 颗亮，后面全灭 | 问题出在**第 N 颗的 DOUT** 或**第 N+1 颗的 DIN**。按第三节的顺序表找到对应丝印编号（例如前 4 颗亮 → 查 D10 的 DOUT 和 D2 的 DIN），先补焊，不行就换第 N+1 颗 |
| 某颗颜色不对或闪烁 | 这颗灯的某个引脚虚焊，补焊；或者灯珠过热受损，换掉 |
| 颜色顺序不对（红绿互换） | 不是焊接问题，是代码里颜色顺序设置不对（WS2812B 一般是 GRB） |
| 上电电流很大、灯发烫 | 有灯焊反了或者有连锡。马上断电，逐颗查 VDD 和 GND |

### 单颗灯返修（热风枪）
1. 热风枪约 300 ℃、小风量，先在周围大范围预热
2. 对着这颗灯吹到锡化开，用镊子夹走
3. 焊盘清理干净后重新点锡膏、放新灯，再吹回去
4. 相邻的灯可以用铝箔/高温胶带挡一下，避免透镜被吹坏

## 八、焊完给自己打分

- [ ] 12 颗灯方向全部正确（缺角/GND 对三角）
- [ ] 每颗灯侧面 4 个引脚都有饱满的焊点
- [ ] `+` 和 `−` 之间不短路
- [ ] 空载上电电流正常，灯不亮
- [ ] 给数据之后 12 颗都能亮，颜色正确
- [ ] 板面已清洗，引线已固定
