## 一、⚠️ P1/P2/P3 的定义和电机板不一样

> **这是 REF 板上最容易出事的一条,放在第一节。**

`source/dummy/hardware/dummy_boards_manual.pdf` **第 1 页**(这一页的文字能直接提取,不像针脚图是位图):

```
REF controller board ports definitions
P1 - 24V power and CAN bus
P2 - ST-LINK and UART1
P3 - LED ring
```

对照第 2 页的电机板:

| 座子 | Motor-42 / 35 | **REF** | REF 在哪面 |
|---|---|---|---|
| P1 | 24 V + CAN | 24 V + CAN | **背面** |
| P2 | 24 V + CAN(与 P1 同定义) | **ST-LINK + UART1** ← 调试口 | **正面** |
| P3 | **ST-LINK + UART1** | **LED ring**(接灯环板) | **背面**,3 针 |

**烧录口从 P3 挪到了 P2。** 在电机板上养成的「P3 接 ST-Link」习惯,到 REF 上会把 ST-Link 插进灯环口。

两道物理保护:

- REF 的 P3 是 **3 针**(`Header 3` / `CONN-TH_HC-ZH1.5-3A-S`),6 针插头插不进去
- P1 在背面、P2 在正面,不在同一面

但 **P1 和 P2 都是 6 针、都在板边** —— 还是贴标签。

> 顺带:`LedRing` 那块小板就是接 REF 的 **P3**。

## 三、正面元件

### 1. 无线与 USB(右半边)

| 位号 | 实物 | 作用 |
|---|---|---|
| **U2** | 中间偏右的大 QFN(7×7,48 脚) | **ESP32-PICO-D4**。WiFi + 蓝牙。⚠️ BOM 写 `ESP32_SIP`,采购单写 `ESP32-PICO-D4`,**同一个东西两个叫法** |
| **A1** | 最右边米色长条,印 `RainSun` | **板载陶瓷天线**,贴板边。天线下方与周围须净空(不铺铜)—— 板子右上角那块空白就是为它留的 |
| **U7** | 右上那块大米色矩形 | **nRF24L01 模块座**(封装 `NRF24L01-MODULE`)。不是芯片,是**插模块的焊盘**,2.4 G 遥控用 |
| **U1** | 右下小 QFN(5×5,28 脚) | **CP2102** USB 转串口 |
| **J1** | 最下方金属壳 | **USB Type-C**(`TYPEC-303-ACP16`) |
| **R8 / R9** | 紧挨 J1 的两颗 0402,**5.1 kΩ** | **Type-C 的 CC1 / CC2 下拉电阻** |
| **Q1** | J1 与 U1 之间的 6 脚小管(SOT-563) | **BC847BVC-7 —— 一个封装两颗 NPN**。配 R4、R6 两颗 12 kΩ |

**关于 R8 / R9(5.1 kΩ)**:USB-C 规范规定设备端(UFP)必须在 CC 脚对地接 5.1 kΩ,充电器靠它识别「这是个取电设备」。**少焊一颗就不认**,是 Type-C 板子最常见的翻车点。

**关于 Q1 那一组** ❓:**几乎可以肯定是 ESP32 的一键下载电路**。经典做法是 CP2102 的 DTR/RTS 两根握手线经两颗 NPN 交叉驱动 ESP32 的 EN(复位)和 IO0(下载模式),烧录工具据此自动进下载模式,不用按键。

特征全部吻合:双 NPN + 两颗等值 12 kΩ + 位置正好夹在 CP2102 和 ESP32 中间。
**验证**:原理图上 `Ctrl` 点 Q1 的两个基极,看是否连到 CP2102 的 DTR / RTS。

### 2. 电源第一级(横跨两面)

| 位号 | 面 | 作用 |
|---|---|---|
| **P1** | 背面 | 24 V + CAN 进线 |
| **D2** | 正面 | **SS54 肖特基**,串在 24 V 入口防反接 |
| **D3** | 正面 | **SMBJ28CA TVS**,并联泄浪涌 |
| **C6** | 背面 | **220 µF / 25 V** 母线储能(背面那颗大圆柱) |
| **U8 + L1 + D4** | 正面 | **ME3116 降压 DC-DC** + 6.8 µH 电感 + B5819W 续流二极管 |
| **R11(10 K)/ R14(1.8 K)** | 正面,紧贴 U8 | 反馈分压 ❓ |

> **一个漂亮的交叉印证**:Motor-42 上 ME3116 的反馈分压也是 **10 K + 1.8 K**(那边叫 R13 / R14)。
> **两块板用同一颗芯片、同一组分压值 ⇒ 中间电压相同。** 在 42 板上算出的值可直接搬过来。

### 3. CAN 与人机

| 位号 | 实物 | 作用 |
|---|---|---|
| **U11** | 中间偏左的 SO-8 | **SN65HVD232D** CAN 收发器(与电机板同款) |
| **`1`** | 顶部大黑屏 + 橙色排线 | **OLED 显示屏**。⚠️ 它的位号**就是数字 `1`**,不是笔误 —— 在 AD 里按位号搜索时会很迷惑 |
| **U4** | 左侧银色方块 | **MLT-7525 蜂鸣器**(7.5 × 7.5 mm) |
| **LED1 + R18** | 右上角 | 状态灯 + 2 kΩ 限流 |

### 4. 左侧的三个开关器件

| 位号 | 器件 | 类型 |
|---|---|---|
| **Q2** | AO3400A | N 沟道 MOS,30 V / 5.8 A |
| **Q3** | AO3401A | **P** 沟道 MOS,30 V / 4.2 A |
| **VT1** | S8050 | NPN 三极管,500 mA |

三个都挨着 P3(灯环口)和 U4(蜂鸣器)那一侧。

❓ **推测**:P 沟道 MOS 做灯环供电的高边开关(WS2812 灯环要单独控制通断),NPN 驱动蜂鸣器,N 沟道做电平/使能。**这是位置推断,未验证。**

> **验证价值很高**:`<V2>/1.Hardware/README.md` 写了改进第 5 条「将 led ring、buzzer 控制从 ESP32 改到 STM32 MCU」。
> 所以这几个管子的栅极/基极应该连到 **U12(STM32F405)** 而不是 U2(ESP32)。**追这条线就能验证 README 这句话是否属实。**

## 四、背面元件

> 3D 底面视图是镜像的,左右和正面相反(例:P3 在图上靠右,实际 X 坐标最小)。

| 位号 | 实物 | 作用 |
|---|---|---|
| **U12** | 正中间 64 脚大方芯片 | **STM32F405RGT6**(LQFP-64)。1 MB Flash / 128 KB SRAM + 64 KB CCMRAM,168 MHz。**这块板上唯一跑 FreeRTOS 的 MCU** |
| **Y1 + C7 / C9** | U12 左侧金属封装 + 两颗 20 pF | **8 MHz 晶振**。⚠️ **不是 12 MHz** —— 电机板才是 12 MHz |
| **U10** | 上方小 QFN(24 脚) | **MPU6050** 六轴 IMU |
| **C24(2.2 nF)** | U10 旁边 | MPU6050 的 **CPOUT 电荷泵电容**,数据手册指定值,**不能换成 0.1 µF** |
| **U3 + L2 + C5/C10/C17** | 右侧 SOT23-5 + 2.2 µH 电感 + 三颗 22 µF | **SY8089 同步降压,2 A** → 3.3 V |
| **P1** | 下方 6P 座 | 24 V + CAN |
| **P3** | 右侧 3P 座 | **灯环** |
| **R24** | 紧挨 P1 | **120 Ω,标注 `120R/NC`** |

### ① 8 MHz 这个数,固件能印证 ✅

索引第七章记的 F405 时钟配置:`HSE + PLL M=4 / N=168 / P=2 → 168 MHz`。代入:

```
8 MHz  ÷ 4   = 2 MHz     (PLL 输入,规格要求 1~2 MHz ✓)
2 MHz  × 168 = 336 MHz
336 MHz ÷ 2  = 168 MHz   ✓
```

换成 12 MHz 就对不上。**硬件和固件在这里闭合。**

### ② 两级电源,这是 V2 的核心改动

```
24V ──D2 防反接──► ME3116(U8) ──► 中间电压 ──► SY8089(U3, 2A) ──► 3.3V
       正面              正面                         背面
```

`1.Hardware/README.md` 改进第 3 条:**「添加 switching ldo,供电电流最大 2A,fix 原版 mcu ldo 电流过小,温度过高 issue」** —— 指的就是 U3 这颗 SY8089。

原版用线性 LDO,F405 + ESP32 + OLED 一起跑时压降全变成热;换成同步开关电源后效率高、不烫。

**对比电机板**:那边第二级是 **LP2992 LDO**(负载小,够用)。
**同一个项目里,两块板按负载选了不同方案** —— 值得记住的工程判断。

### ③ `R24` 标注 `120R/NC` = 留位置但默认不焊

CAN 总线**只有首尾两个节点**该接 120 Ω 终端电阻。设计者把 REF 的终端电阻做成「焊盘预留、默认空装」,按实际拓扑决定。

**对比电机板**:那边用 **S1 拨码开关的第 4 位**通断 R12。

> 两块板解决同一个问题,一个用开关、一个用焊不焊 —— 因为电机板有 6 块、位置不定;主控只有 1 块,通常就在总线一端。

## 五、与 Motor-42 同构的部分

| 功能块 | REF | Motor-42 | 读法 |
|---|---|---|---|
| 24 V 入口保护 | D2 SS54 + D3 SMBJ28CA | D1 SS54 + D2 SMBJ28CA | **完全一样** |
| 一级降压 | ME3116 + 6.8 µH | ME3116 + 6.8 µH | **完全一样** |
| CAN 收发 | SN65HVD232D | SN65HVD232D | **完全一样** |
| MCU 去耦 | 一堆 0.1 µF 围着 U12 | 一堆 0.1 µF 围着 U3 | 套路一样 |
| 二级稳压 | **SY8089 开关,2 A** | LP2992 LDO | **按负载选的不同方案** |

**所以 REF 真正的「新东西」只有三块**:

1. ESP32 + 天线 + nRF24(无线)
2. CP2102 + Type-C(USB)
3. MPU6050(IMU)

其余都是在 42 板上读过的电路换了个位号。**读 REF 时只啃这三块,其余快速扫过即可。**

## 七、焊接难度与顺序

### ⚠️ REF 比电机板高一级

| | 正面 | 背面 |
|---|---|---|
| 难封装 | CP2102 **QFN-28**、ESP32 **QFN-48** | MPU6050 **QFN-24**、STM32F405 **LQFP-64** |

**两面都有引脚藏在芯片底下的 QFN** —— 没法像 42 板那样「一面回流 + 一面烙铁手焊」。

### 顺序

1. **先回流背面**(U12、U10、U3 及周边,都是扁平件、没有高件)
2. **再回流正面**(U2、U1 及 0402 群)
3. **最后烙铁手焊**:OLED、nRF24 模块、Type-C、蜂鸣器、P1/P2/P3 —— 高的、重的、插件的全部留到这一步

**第二次回流时背面朝下**,靠焊锡表面张力吊着。QFN 和 LQFP 焊盘面积大、自重轻,吊得住;但**板子不能直接压在加热台上**,要用支撑架或垫块架空。

> **建议整体顺序:42 → 35 → REF。** 先用 42 板把流程跑顺(它只需要一次回流),再上这块。

| 看到的 | 判断 |

| **大片空白 + 零星铜点** | ❌ **被当正片处理了,板子会全废** —— 截图找客服确认,别自己赌 |
